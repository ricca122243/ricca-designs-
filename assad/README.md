# ASSAD — демо-сайт корпусной мебели на заказ (Алматы)

Статика без сборки: `index.html`, `css/styles.css`, `js/data.js` (все тексты, цены, контакты), `js/scenes.js` (векторные рендеры фасадов, заменяются фото), `js/main.js`, GSAP в `vendor/`.

Стиль унаследован от ricca.design: белая бумага, Cormorant + Montserrat, нумерация разделов, чёрные блоки.

## Что умеет
- Каталог с переключением материала фасадов прямо на карточке.
- Калькулятор по погонным метрам: изделие × материал × фурнитура → ориентир и смета в WhatsApp.
- Запись на замер: день, время, адрес → WhatsApp.
- Инструмент «водяной знак»: фото → логотип-паттерн → скачать. Работает в браузере, фото никуда не отправляется.
- Галерея с защитой: водяной знак и запрет правого клика.
- Анимации: появление заголовка, параллакс hero, счётчики, наклон карточек, бегущая строка.

## Запуск
```bash
npx http-server -p 8080 assad
```
Контакты из 2ГИС, цены демонстрационные — правятся в `js/data.js`.
