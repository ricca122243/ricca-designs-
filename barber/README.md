# Barber Shop 86 (Алматы) — сайт с онлайн-записью

Статика без сборки: `index.html`, `css/styles.css`, `js/main.js`, данные в `js/data.js`.

## Как заменить данные
Всё содержимое (филиалы, часы, WhatsApp, услуги, цены, мастера, причёски, отзывы, галерея) лежит в `js/data.js`. Данные собраны с 2ГИС и barbershop86almaty.tilda.ws (октябрь 2026).

**Что уточнить у владельца:** уровень мастеров (`level: 'lead' | 'senior'` — от этого зависит цена) и в каком филиале кто работает; график каждого мастера (`days`). Сейчас все мастера отмечены как ведущие и доступны во всех филиалах.
- У причёски можно указать `img: 'img/style.jpg'` — тогда вместо силуэта будет фото.
- У каждого филиала свой `whatsapp` (без «+»): заявка уходит в выбранный филиал готовым сообщением.
- График мастера: `days: [1,2,3,4,5,6]` (0 — воскресенье).

## Запись
Визард: филиал → услуга → мастер → день и время → контакты → кнопка «Отправить в WhatsApp» (+ файл .ics в календарь).
Занятость слотов сейчас имитируется (нет бэкенда). Для реальной занятости: встроить виджет Altegio/YClients или подключить базу (Supabase).

## Запуск
```bash
npx http-server -p 8080 barber
```
