# Барбершоп — сайт с онлайн-записью

Статика без сборки: `index.html`, `css/styles.css`, `js/main.js`, данные в `js/data.js`.

## Как заменить данные
Всё содержимое (название, адрес, часы, WhatsApp, услуги, цены, мастера, причёски, отзывы) лежит в `js/data.js`.
- У причёски можно указать `img: 'img/style.jpg'` — тогда вместо силуэта будет фото.
- `whatsapp` — номер без «+», туда уходят заявки готовым сообщением. `telegram` — username, появится вторая кнопка.
- График мастера: `days: [1,2,3,4,5,6]` (0 — воскресенье).

## Запись
Визард: услуга → мастер → день и время → контакты → кнопка «Отправить в WhatsApp» (+ файл .ics в календарь).
Занятость слотов сейчас имитируется (нет бэкенда). Для реальной занятости: встроить виджет Altegio/YClients или подключить базу (Supabase).

## Запуск
```bash
npx http-server -p 8080 barber
```
