ELUNA

Как запустить сайт

В этой папке — весь сайт целиком: страницы, стили, анимации, шрифты, картинки. Её нужно один раз загрузить на хостинг — и сайт появится в интернете по ссылке.

Способ 1 · быстро и бесплатно · 2 минуты

Netlify Drop

  1. Откройте app.netlify.com/drop и зарегистрируйтесь (через Google или e-mail).
  2. Перетащите всю папку ELUNA-site в окно браузера.
  3. Через минуту сайт открыт по ссылке вида что-то.netlify.app — её можно сразу отправлять клиентам.
  4. Своё имя: Site settings → Change site name → например eluna-kz.netlify.app.
  5. Свой домен (например eluna.kz): Domain management → Add a domain и прописать у регистратора домена записи, которые покажет Netlify. HTTPS включится сам.

Обновить сайт после правок: Deploys → перетащить новую папку ещё раз.

Способ 2 · свой домен .kz

Казахстанский хостинг (PS.kz, Hoster.kz и другие)

  1. Купите домен (.kz) и самый простой тариф хостинга (подойдёт любой — сайт статический, без базы данных и PHP).
  2. В панели хостинга откройте «Файловый менеджер» (или подключитесь по FTP, например FileZilla).
  3. Зайдите в папку сайта — обычно public_html или www — и загрузите туда содержимое папки ELUNA-site (не саму папку, а то, что внутри: index.html, css, js, img …). Удобно загрузить архив .zip и нажать «Распаковать».
  4. Включите в панели бесплатный SSL-сертификат (Let’s Encrypt), чтобы адрес был https://.

Файл .htaccess уже внутри: ускоряет загрузку (кеш и сжатие) и показывает красивую страницу 404.

Способ 3 · бесплатно, для тех, кто знаком с GitHub

GitHub Pages

  1. Создайте репозиторий, загрузите в него содержимое папки ELUNA-site.
  2. Settings → Pages → Source: Deploy from a branch, ветка main, папка / (root).
  3. Сайт будет по адресу имя.github.io/репозиторий; свой домен — там же, в поле Custom domain.
После запуска — проверьте

Что посмотреть и где поменять

  • Откройте сайт по ссылке на телефоне и компьютере: луна, расслойка матраса, карта, выбор размера.
  • Кнопка WhatsApp — ведёт на +7 707 955 08 08. Номер меняется в файле js/main.js, строка const WHATSAPP = '77079550808'.
  • Цены — там же, в js/main.js: const PRICES = { air: 125000, balance: 220000, prime: 280000, royal: 1250000 } и старая цена Prime в OLD_PRICES.
  • Реквизиты (ИП/ТОО, БИН, адрес, e-mail) — впишите вместо пометок [заполнить] в privacy.html и legal.html.

Важно: если открыть index.html двойным кликом прямо с компьютера, сайт откроется, но 3D-луна и часть эффектов браузер с диска не запускает (защита браузера). Настоящий вид — только по ссылке после загрузки на хостинг.
