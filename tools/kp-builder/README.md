# Конструктор КП RICCA DESIGNS

Страница, где владелец и менеджеры собирают коммерческое предложение и скачивают PDF.

- Адрес: https://ricca-kp.netlify.app. Это отдельный сайт на Netlify (`ricca-kp`), живой сайт ricca.design он не трогает.
- Поисковики сайт не индексируют.

## Что умеет

- **Каталоги «Диваны», «Кровати», «Пуфы».** Модели берутся с сайта. Модель можно включить или выключить, выбрать до трёх фото на белом, указать цену («цена от») и размер.
- **Фото «в интерьере»** — отдельный слайд на весь экран. У кроватей есть готовые интерьеры с Pinterest, к любой модели можно загрузить свои.
- **«+ Новая модель».** Название, описание, фото на белом и в интерьере, цена. Модель появляется в каталоге у всех.
- **«Своё КП».** Любые модели из всех каталогов и новые модели, у каждой своя цена и количество, в PDF есть слайд «Итого».
- **Оформление по времени года, как на сайте.** Зима — светло-голубая со снегом, весна — мятная, осень — серо-стальная, лето — белое. По умолчанию выбирается по дате в Алматы.
- **Слайды:**
  - обложка;
  - модели;
  - итого;
  - условия (свои для каждой вкладки);
  - «Нам доверяют» (логотипы с сайта и свои, любой можно скрыть);
  - «Пришлите фото»;
  - контакты.

## Где хранятся данные

- **Цены, выбор фото, новые модели, «Своё КП», логотипы.** Хранятся на Netlify в хранилище Blobs (`kp-docs`, `kp-photos`), через функцию `/api` (`src/functions/kp.mjs`). Чтобы читать и менять общие данные, нужен код доступа.
- **Код доступа.** Это переменная `KP_CODE` в настройках сайта `ricca-kp` на Netlify (Site configuration → Environment variables). В репозиторий код не кладём. Чтобы поменять код: изменить переменную и заново выложить сайт.
- **Без кода.** Всё работает, но сохраняется только в памяти этого браузера.
- **Фото с Pinterest.** В репозиторий не кладём, потому что репозиторий публичный. В `interiors.json` лежат ссылки, сборка скачивает файлы в `.cache/int`.

## Обновить после изменений на сайте

Новые модели и фото в `ricca/js/catalog-data.js` и логотипы в блоке «Нам доверяют» в `ricca/index.html` попадают в конструктор при следующей сборке.

1. Собрать сайт конструктора:

   ```
   python3 tools/kp-builder/build.py    # → tools/kp-builder/_site
   ```

2. Выложить на Netlify. Через Netlify MCP: `deploy-site` с siteId `bb7e6419-106a-4bd7-a8e3-5bd521a092bf`, команду из ответа запустить внутри `tools/kp-builder/_site`. Функция `/api` и пакет `@netlify/blobs` собираются на стороне Netlify.

Проверить локально, без Netlify:

```
python3 tools/kp-builder/build.py
KP_CODE=1234 PORT=8790 node tools/kp-builder/dev-server.mjs
```

Затем открыть http://localhost:8790. Это то же `/api`, но данные хранятся в памяти и пропадают после перезапуска.

## Файлы

| Файл | Что это |
|---|---|
| `src/index.src.html` | Страница: интерфейс, слайды, сборка PDF (html2canvas + jsPDF) |
| `src/functions/kp.mjs` | Общее хранилище `/api` на Netlify |
| `build.py` | Сборка `_site`: каталог с сайта, фото, интерьеры, логотипы |
| `extra-photos.json` | Доп. фото кроватей из `ricca/img/catalog`, которых нет в окне модели на сайте |
| `interiors.json` | Интерьеры кроватей с Pinterest: ссылка, размер, `pre` = стоит в КП по умолчанию |
| `dev-server.mjs` | Локальная проверка |
