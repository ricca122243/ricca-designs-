# Карта переименования моделей (F2, правки заказчика 10 октября)

Внутренний файл, вне папки сайта. Прежние id изделий (с названиями с листов фабрики) → новые нейтральные id. На сайте модель
показывается как «№ NN» (номер из нового id), пока заказчик не утвердит свои названия RICCA: их вписывают в
`window.RICCA_MODEL_NAMES` в ricca/js/catalog-data.js. Файлы `img/catalog/p-<прежний id>*.webp` переименованы в `p-<новый id>*.webp`.
Старые ссылки вида #item-<прежний id> больше не открывают окно изделия.
