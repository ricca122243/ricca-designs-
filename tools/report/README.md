# Отчёты владельцу о работе над сайтом (PDF A4, 3 страницы)

Вид — как «Отчёт 15–17 ноября», который понравился владельцу: стр. 1 — заголовок, 4 экрана с телефона, 4 крупные цифры;
стр. 2 — «Раздел 1. Что сделано» таблицей; стр. 3 — «Раздел 2. Что нужно от вас» (галочки) и «Раздел 3. Что дальше».

Как собрать новый (пример — otchet-18-27-noyabrya.html):
1. Скопировать прошлый отчёт, поменять даты и тексты; пункты брать из DESIGN.md, раздел 7, и `git log --since=…`.
2. Экраны: Playwright, iPhone 13, живой ricca.design → `shots/<имя>-r.jpg` (ширина 600, пропорция 0,47).
3. Папку с отчётом раздать сервером вместе с шрифтами сайта (ссылки css → ricca/css, fonts → ricca/fonts, img → ricca/img),
   `<base href>` — на этот сервер (иначе Montserrat не подхватится), затем:
   `node tools/report/pdf.cjs http://localhost:8790/otchet.html <out.pdf> <prefix-картинок>` — печатает запас до подвала
   на каждой странице (должен быть > 0) и какие шрифты загрузились.
