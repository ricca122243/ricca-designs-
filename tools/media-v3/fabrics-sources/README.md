# Источники новых коллекций тканей (внутреннее, на сайт не идёт)

По файлу на коллекцию: официальная страница поставщика, все цвета (код, название, адрес страницы и фото), характеристики, заметки
о расхождениях сайта с биркой на вешалке. Собрано 24 ноября 2026 с официальных сайтов; каждую коллекцию заново сверил второй
независимый проход (число и порядок цветов, привязка «код → фото», характеристики).

Оригиналы фото в репозиторий не кладём (`ricca/content/fabrics/_official/` в .gitignore). Чтобы пересобрать коллекцию: скачать фото
по `image_url` в папку `<raw>/<id>/img/<код>.<ext>`, положить рядом этот файл как `meta.json` и запустить
`python3 tools/media-v3/fabrics-add.py <raw> <id>`. Что идёт на сайт и в каком порядке — `tools/media-v3/fabrics-new.json`.

Не собраны: VIRGINIA и вешалка «Лэзертач» — сайт поставщика (ltex.ru) отсюда не открывается.
