## Как продолжить
1. Окружение: Python с `bpy` (5.x), `numpy`, `scipy`, `scikit-image`, `Pillow` (`pip install bpy scikit-image scipy pillow` в отдельный venv).
2. Сборка: `python galso_demo.py <out> --glb` → сверка `python photofit.py galso <out>/galso.glb <out>/fit --turn` → смотреть `sheet.jpg`, `turn.jpg`.
3. Сначала — канты на версии с демо (просьба владельца), проверить в конструкторе на телефоне, выложить на демо.
4. Потом — довести `galso.py` и `runvo.py` (задание и критерии проверки — в истории сессии и в шапках файлов), независимая проверка, показать владельцу.
5. На ricca.design ничего не выкладывать без «да» владельца (там всё ещё старые неверные 3D этих кресел).
