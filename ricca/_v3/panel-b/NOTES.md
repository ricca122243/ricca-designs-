# Прототип B «Galerie» — заметки сборщика

Папка: `ricca/_v3/panel-b/` (`index.html`, `style.css`, `script.js`, `build.py`, `shots/`). Открывается с `python3 -m http.server` из корня репозитория: `/ricca/_v3/panel-b/`. Ассеты — `../../fonts`, `../../img`, `../../css/fonts-v3.css`. Внешних запросов нет (только клики на wa.me / instagram / 2gis / netlify).

`build.py` — идемпотентный шаг: подставляет путь монограммы RD, превращает `href="wa:ключ"` в ссылки wa.me с готовым текстом (CONTENT-V3 §5, §26, §27 дословно), расставляет неразрывные пробелы в текстовых узлах. После правки `index.html` запускать повторно.

## Подпись варианта (отклонения от чисел системы, в рамках PANEL-BRIEF B)
- Рама «экспонат»: паспарту 16px `--paper-2`, рамка `--line-2`, внутренняя линия `--line-3`; hover — рамка `--ink` и `scale(1.015)` изображения. Никаких подсветок, теней и градиентов.
- Таблички `.plate`/`.cover__cap`: Montserrat 11px caps + Cormorant italic 15–17px.
- h2 56px (меньше максимума 72), hero 96px; подписи к типам диванов — Cormorant 22px.
- Лайтбокс белый (rgba(247,245,240,.96)), подложка диалогов — чёрная .55.
- Свечение луны §1.5 выключено (`.eluna::before { content: none }`): без самой луны оно читалось как пятно. Включить в сборке вместе с `moon-hd-1280.webp`.
- Золото только внутри `.chapter--noir`: на белом `--gold: var(--ink)`, бейдж «Новинка» в указателе каталога рисуется чёрным.

## Решения, которые надо знать
- Нумерация залов — по порядку страницы (01 Диваны … 06 ELUNA); обложки проектов нумеруются отдельно «01 — Гостиная …».
- Hero: залитая — «Написать в WhatsApp», контурная — «Посетить шоурум» (CONTENT-V3 §2).
- Royal: «1 250 000 ₸ · за 1600 × 2000 мм · для других размеров цена может отличаться», без «от».
- «≈ ₸ за ночь» — цена ÷ (15 × 365), сноска: срок службы — факт ELUNA, не обещание.
- Фото — `img/v3/*` + CSS-дуотон; ни одно не крупнее 2× исходника (hero ≤ 480 CSS px, на планшете ≤ 520; лайтбокс ≤ 560).
- Unbounded загружается на первом экране десктопа только словами «ELUNA» в указателе каталога и в подвале (§1.5 разрешает).
