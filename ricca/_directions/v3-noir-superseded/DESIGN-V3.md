# RICCA DESIGNS — дизайн-система и спецификация страницы. Версия 3 («новый сайт с нуля», 8 октября)

Документ для сборщиков нового сайта `ricca/` (статический, без сборки). Он единственный описывает, **как выглядит и ведёт себя** новый сайт; **что на нём написано** — в `content/catalog.md` и `content/copy.md`; **что правда** — в `BRIEF.md` (раздел «НОВЫЙ САЙТ С НУЛЯ»). Если этот документ и бриф расходятся — прав бриф. Если документ и копи-дек расходятся в тексте — прав копи-дек.

Статус: спецификация, по которой три сборщика делают три прототипа (см. `PANEL-BRIEF.md`). Все числа ниже — рабочие значения, их можно двигать на ±10 %, не ломая отношений между ними; токены, шрифты, факты и структура шапки/подвала не обсуждаются.

Обозначения: `--token` — CSS-переменная на `:root`; `key.name` — строка из `catalog.md` / `copy.md`; `wa.*` — готовое сообщение WhatsApp из `catalog.md` §16.2; **[TODO]** — факт, которого нет, на сайт не идёт.

## 1. Палитра

### 1.1 Чёрная основа

Чёрный нейтральный с едва холодным подтоном (не синий космос ELUNA и не тёплый орех прежних сборок). Три уровня глубины + линии.

```css
:root {
  --bg:        #0C0C0E;   /* страница. «Дорогой чёрный»: на OLED не сливается с рамкой телефона */
  --bg-2:      #121214;   /* большие панели, подвал, шапка при скролле */
  --bg-3:      #19191C;   /* карточки, поля, чипы, кнопка «Задать вопрос» (как в макете: плашка чуть светлее фона) */
  --bg-4:      #202024;   /* hover карточки, активный чип */
  --line:      rgba(244,240,232,.14);   /* волосяные линии (в макете заказчика линия над контактами заметна — не .08) */
  --line-2:    rgba(244,240,232,.28);   /* активная рамка, hover кнопки-контура, рамка фото */
  --line-3:    rgba(244,240,232,.06);   /* деления внутри таблиц и списков */
  --shadow:    0 24px 60px rgba(0,0,0,.55);   /* только диалог и выдвижная «Подборка» */
}
```

Глубина без коричневого: разрешены виньетка `radial-gradient(120% 80% at 50% 0%, rgba(244,240,232,.04), transparent 60%)` на hero и ELUNA-блоке и зерно `opacity .025` (SVG `feTurbulence`, как у ELUNA, `position: fixed; pointer-events: none`). Зерно на телефоне — только если `TIER !== 'low'` (см. §6.6).

### 1.2 Молочная шкала (текст на чёрном)

```css
:root {
  --ink:    #F4F0E8;                    /* заголовки, цены, текст кнопок. 17,2 : 1 на --bg */
  --ink-2:  rgba(244,240,232,.76);      /* основной текст, лиды. 10,0 : 1 */
  --ink-3:  rgba(244,240,232,.66);      /* подписи, капс-лейблы, меню в покое. 7,7 : 1 */
  --ink-4:  rgba(244,240,232,.28);      /* только декор: номера секций, плейсхолдер, выключенные чипы — не для чтения */
}
body { background: var(--bg); color: var(--ink-2); }
h1, h2, h3, .price, .button--fill { color: var(--ink); }
```

«Чуть белее, чем ELUNA» выполняется: у ELUNA вторичный текст `.66/.54`, здесь `.76/.66`, линии `.14` против `.10`.

### 1.3 Молочные секции (1–2 на страницу: «Как устроен матрас ELUNA» обязательно; вторая — по варианту, см. PANEL-BRIEF)

```css
.section--paper {
  --bg: #F4F0E8; --bg-2: #EEE9E0; --bg-3: #E7E1D7; --bg-4: #DED7CB;
  --ink: #141313;                       /* 16,3 : 1 */
  --ink-2: rgba(20,19,19,.74);          /* 7,5 : 1 — основной текст на молочном */
  --ink-3: rgba(20,19,19,.60);          /* 4,7 : 1 — мелкие подписи ≥ 13px, не ниже */
  --ink-4: rgba(20,19,19,.26);
  --line: rgba(20,19,19,.12); --line-2: rgba(20,19,19,.28); --line-3: rgba(20,19,19,.06);
  background: var(--bg); color: var(--ink-2);
}
```

Так все компоненты переезжают на молочное без правок. Кромка между чёрным и молочным — резкая, без градиентов (как у Apple). Молочный — именно `#F4F0E8` (тот же, что `--ink`): света фотографий в дуотоне `img/mono/*` совпадают с бумагой, тени — с `--bg` прежней базы; для новой базы фото пересобрать рецептом из `img/MANIFEST.md` («mono/») с парой `#0C0C0E` / `#F4F0E8`.

### 1.4 Золото — один hex

```css
:root { --gold: #C8A86B; }   /* 8,6 : 1 на --bg; 7,7 : 1 на --bg-3 — читается как текст на чёрном */
```

| Разрешено | Запрещено |
|---|---|
| Основной телефон в контактах и подвале (текст, как в refs/04) | Заголовки, лиды, любые абзацы |
| Бейдж «Выбор ELUNA» (текст + рамка 1px) | Заливка кнопок, фоны карточек, градиенты |
| Волосяная линия 1px под ценой флагмана и над строкой цены в таблице сравнения | Иконки (они молочные) |
| Точка-разделитель в eyebrow внутри блока ELUNA (3×3px) | Точки в eyebrow вне блока ELUNA (там — `--ink-4`) |
| `::selection` и `:focus-visible` (2px) на чёрном | Любой текст на молочном: контраст золота на `#F4F0E8` — 2,0 : 1. На молочном золото живёт только как линия 1px или точка (не текст) |
| Текст-ссылка «Сайт ELUNA» при hover (подчёркивание золотом, текст молочный) | Тени, свечение (`text-shadow`) — кроме цены Prime внутри блока ELUNA, где это цитата стиля ELUNA |

### 1.5 Акцент ELUNA — космос только внутри `#eluna`

Блок ELUNA — «другой продукт внутри сайта». Его среда объявлена на секции, а не на `:root`, и не вытекает наружу:

```css
.eluna {
  --e-bg: #08090D;                /* чуть холоднее и глубже страницы; это же значение — в lighten холста кадров (§6.3) */
  --e-warm: 255, 243, 226;        /* тёплый прожектор (луна) */
  --e-cool: 196, 208, 255;        /* холодная подсветка краёв */
  --e-font: 'Unbounded', 'Montserrat', sans-serif;
  background: var(--e-bg);
  position: relative; isolation: isolate; overflow: hidden;
}
```

Что из космоса ELUNA разрешено внутри блока — и только там:
1. **Слабое звёздное поле**: один `<canvas>` на секцию (не `fixed`), плотность 1 звезда на 9 000 px² десктоп / 14 000 телефон (у ELUNA 5 000 / 8 000 — здесь вдвое реже), радиус 0,3–1,4px, альфа 0,18–0,6; мерцания и метеоров нет; `reduced-motion` — статично; выключается, если `TIER === 'low'`.
2. **Свечение луны**: `radial-gradient(closest-side at 84% 12%, rgba(var(--e-warm), .10), transparent 70%)` на вступлении блока; сама луна `img/eluna/moon-hd-1280.webp` — только как декор вступления на десктопе (`loading="lazy"`, ширина ≤ 42vw, обрезана краем секции), на телефоне луны нет. WebGL-шар ELUNA не переносится.
3. **Unbounded** для заголовков, названий моделей, цен и цифр фактов внутри блока; текст внутри блока остаётся Montserrat (а не Inter — второй гротеск на странице не нужен).
4. **Виньетка** `radial-gradient(80% 60% at 50% 40%, transparent, rgba(0,0,0,.45))` под сценой.

Снаружи блока ELUNA звёзд, луны и Unbounded нет — кроме двух подписей: бейдж «Новинка · ELUNA» в навигации по каталогу (§5.3) и ссылка «Сайт ELUNA» в подвале (слово ELUNA в Unbounded 500, размер 1em). Вариант C «Atelier Cosmos» (PANEL-BRIEF) может дать намёк на звёзды в hero — не выше альфы .12 и не больше 40 звёзд на экран.

## 2. Типографика

Все шрифты локальные, `fonts/fonts.css` (Cormorant, Montserrat) + `css/fonts-eluna.css` (Unbounded). Playfair, Noto Serif Display, Manrope, Ysabeau, Inter на новом сайте **не подключаются**.

```css
:root {
  --serif: 'Cormorant', 'Garamond', Georgia, serif;
  --sans:  'Montserrat', system-ui, -apple-system, 'Segoe UI', Roboto, Arial, sans-serif;
  --e-font: 'Unbounded', var(--sans);
}
```

Предзагрузка на первом экране (ровно четыре файла): `cormorant-cyrillic-var-normal`, `cormorant-cyrillic-var-italic`, `montserrat-cyrillic-var-normal`, `montserrat-latin-var-normal`. Латиница Cormorant подгрузится сама по `unicode-range`, Unbounded — только когда блок ELUNA в 75 % от вьюпорта (`document.fonts.load('500 1em Unbounded')` из наблюдателя секции).

### 2.1 Cormorant — дисплейная антиква RICCA

| Роль | 1440 | 390 | Начертание | Интерлиньяж / трекинг |
|---|---|---|---|---|
| `h1` hero | 128px (`clamp(60px, 8.6vw, 128px)`) | 60px | 400, строка-акцент — italic 400 | 0,96 / −0,015em |
| `h2` секция | 72px (`clamp(42px, 4.9vw, 72px)`) | 42px | 400 | 1,02 / −0,01em |

Правила:
- Курсив — одна строка или одно-два слова в заголовке (`<em>`), как «по мерке» на refs/06. Не больше одного курсивного акцента на заголовок, не в каждом заголовке подряд: hero, 1–2 секции, тезис ELUNA-манифеста — нет (там Unbounded).
- Строки hero переносятся вручную `<br>` на десктопе: «Мебель / *по мерке* / вашего дома»; на телефоне те же три строки (60px влезает в 350px при самой длинной строке «вашего дома»). Вторая строка сдвинута вправо на 2 колонки (desktop) / 24px (phone) — ритм с refs/06.
- Cormorant по умолчанию даёт старостильные цифры → на любые числа в антикве `font-variant-numeric: lining-nums tabular-nums`.
- Вес 400 на чёрном фоне выглядит тоньше, чем на молочном (refs/06): для hero/h2 на `--bg` допустим 450 через `font-variation-settings: 'wght' 450`; на молочном — 400.
- Минимальный кегль Cormorant — 15px. Для подписей меньше — Montserrat.

### 2.4 Цифры, цены и знак ₸ — проверено по файлам шрифтов

- Знак **₸ (U+20B8) есть только в `Unbounded-300/500`**. В локальных подмножествах Montserrat, Cormorant, Inter и `fonts/site/*` его **нет** — браузер подставит системный шрифт, и знак «выпадет» из строки. Поэтому:
  - все цены ELUNA — целиком в Unbounded (карточки, таблица, конфигуратор, липкая плашка);
  - единственная цена вне блока ELUNA — в FAQ («от 125 000 ₸») — оборачивается: `<span class="tenge">₸</span>` с `.tenge { font-family: var(--e-font); font-weight: 300; font-size: .92em; }`;
  - **[TODO]** при доступе к сети собрать подмножество Montserrat с U+20B8 (`pyftsubset … --unicodes="U+0000-00FF,U+0400-045F,U+2000-206F,U+20B8"`) и убрать костыль.
- Табличные цифры везде, где числа стоят колонкой: `font-variant-numeric: tabular-nums` (есть в Montserrat latin, Unbounded, Cormorant latin). Кириллическое подмножество Montserrat `tnum` не несёт — цифры и так в латинском файле, это нормально.
- Формат чисел: разряды через узкий неразрывный пробел `&#8239;` («125 000 ₸», «1 200»), перед ₸ — обычный `&nbsp;`. Старая цена — `<s class="price-old">` с `--ink-3` и `text-decoration-thickness: 1px`, рядом скрыто «старая цена» для скринридера. Диапазон — короткое тире без пробелов («280–300 мм»); размеры — «1600 × 2000 мм» (знак ×, U+00D7).
- Телефоны `tabular-nums`, внутри — `&nbsp;`: `+7&nbsp;(708)&nbsp;480-20-47`.

### 2.5 Типографика текста (из копи-дека, обязательна в разметке)
«Ёлочки», внутри — „лапки“; длинное тире с пробелами; диапазоны коротким тире; `&nbsp;` после предлогов в 1–2 буквы, в «3 года», «ул. Алишера Навои», «208/2», «RICCA DESIGNS»; буква «ё»; точка в конце заголовка не ставится (кроме заголовков из двух предложений — «ELUNA. Наш матрас.»). Eyebrow в HTML обычным регистром, `text-transform` в CSS.

## 3. Сетка, отступы, формы

```css
:root {
  --container: 1360px;
  --gutter: clamp(20px, 5vw, 72px);     /* 390 → 20px; 1440 → 40px (контейнер 1360 = 1440 − 2·40); ≥1600 — 72px */
  --col-gap: 24px;                      /* 12 колонок: (1360 − 11·24) / 12 = 89,3px */
  --sp-1: 8px; --sp-2: 16px; --sp-3: 24px; --sp-4: 40px; --sp-5: 64px; --sp-6: 96px; --sp-7: 144px;
  --section: clamp(80px, 10vw, 144px);  /* вертикальный отступ секции: 390 → 80px; 1440 → 144px */
  --section-tight: clamp(56px, 6vw, 96px);
  --radius: 2px;                        /* кнопки, чипы, поля. Карточки и рамки фото — 0 */
```

## 6. Движение

### 6.1 Принципы
Медленно и точно: ничего не прыгает, ничего не качается. Анимируются только `transform` и `opacity` (плюс `grid-template-rows` у аккордеона). Токены: `--ease-out: cubic-bezier(.16,1,.3,1)`, `--ease-in-out: cubic-bezier(.65,0,.35,1)`; `--t-fast: 250ms`, `--t: 400ms`, `--t-slow: 700ms`, `--t-reveal: 700ms`. Параллакса от указателя, бегущих строк, автопрокрутки карточек, «подсветки букв» ELUNA — нет. `will-change` только у холста сцены, выносок и выдвижных панелей. На странице не больше одного `fixed`-слоя с перерисовкой (зерно) — и он отключается на `TIER === 'low'`.

### 6.2 Появление по скроллу `.reveal`
`opacity: 0; transform: translateY(24px)` → `1 / 0`, 700ms `--ease-out`; внутри группы лесенка `transition-delay: calc(var(--i) * 80ms)` (не больше 6 элементов в лесенке — дальше без задержки). Включается `IntersectionObserver` (`rootMargin: '0px 0px -12% 0px'`, `threshold: .01`), один раз (`unobserve`). Заголовки hero: каждая строка в `<span class="line"><span>…</span></span>` с `overflow: hidden`; внутренний span `translateY(110%) → 0` за 900ms, задержки 0 / 120 / 240ms; лид +300ms, кнопки +420ms, адресная строка +600ms; фото `opacity 0, scale(1.03)` → норма за 1000ms с +300ms. Всё hero-движение стартует по `DOMContentLoaded` без блокировки скролла (интро ELUNA с `overflow: hidden` не переносим). Фото в секциях — `opacity 0, scale(1.02)` → норма, 900ms.

### 6.3 Сцена ELUNA с пином (`#eluna-stage`) — GSAP 3.15 + ScrollTrigger из `ricca/vendor/`
Загрузка: GSAP и ScrollTrigger (118 КБ) вставляются `<script>` динамически, когда `#eluna` входит в `rootMargin: '150% 0px'`; до их загрузки сцена показывает f01 статично. Кадры: `img/eluna/seq/` (1920 × 1080) при `≥ 900px` и `TIER !== 'low'`, иначе `img/eluna/seq720/`; оба набора на одной странице не грузятся. Загрузка кадров начинается при `rootMargin: '75% 0px'`: сначала f01, затем f24, f12, f06, f18, затем остальные по порядку (`img.decode()`), холст рисует ближайший загруженный кадр.

```js
gsap.registerPlugin(ScrollTrigger); ScrollTrigger.config({ ignoreMobileResize: true });
gsap.matchMedia().add({ desk: '(min-width: 900px)', mob: '(max-width: 899px)' }, (ctx) => {
  const D = ctx.conditions.desk;
  const tl = gsap.timeline({ defaults: { ease: 'none' }, onUpdate: render, scrollTrigger: {
    trigger: '#eluna-stage', start: 'top top', end: D ? '+=160%' : '+=120%',
    pin: true, scrub: D ? 0.6 : 0.4, anticipatePin: 1, invalidateOnRefresh: true,
    onUpdate: (self) => { setLabels(self.progress); if (self.progress > .78) showStatement(); } } });
  tl.to(S, { cutO: 1, duration: 8 }, 0)                                         // 0–8: собранный матрас проявляется
    .to(S, { spread: 1, cutS: .92, duration: 60, ease: 'power1.inOut' }, 10)  // 10–70: слои расходятся скрабом
    .to(S, { outS: .82, outY: -6, outO: .35, duration: 18, ease: 'power1.inOut' }, 76)  // 76–94: стопка уходит вглубь
    .to(S, { dark: .55, outO: 0, outY: -14, duration: 10, ease: 'power1.in' }, 90);     // 90–100: затемнение, выход
});
function setLabels(p) { const s = Math.min(1, Math.max(0, (p - .10) / .60));
  labels.forEach((el, i) => el.classList.toggle('is-in', s >= (i + 1) / 7 - .02)); }
```

| Фаза (прогресс пина) | Что видно |
|---|---|
| 0 – .08 | заголовок «Семь слоёв. Одно ощущение.» уже на месте (reveal до пина), матрас проявляется |
| .10 – .70 | слои расходятся вслед за скроллом (назад — собираются); выноска i включается на пороге (i+1)/7 |
| .70 – .78 | пауза: разложенная стопка, все семь выносок |
| .78 – 1 | стопка уходит вглубь и тает, появляется манифест (`.copy--outro`, 350ms), сцена темнеет до 55 % |

Холст: размер = размер кадра на экране (не экрана), `dpr ≤ 1.5`; десктоп — 70 % вписанного кадра, центр по X, 56 % по Y; телефон — 82 % ширины, сдвиг влево на 12 % (справа место выноскам); кроссфейд соседних кадров при `t > .02`; `globalCompositeOperation: 'lighten'` с заливкой **ровно** `--e-bg` (#08090D); эллиптическая виньетка в самом холсте (радиусы .62w / .64h, телефон .56). Выноски: якоря правой грани слоёв в процентах кадра f24 — `Y = [6.5, 17.6, 24.6, 30.8, 40.6, 55.5, 71.0]`, `X = [84, 84, 84, 84, 84, 81.3, 78.1]`; линия 40° длиной 32px (телефон 14px) → вертикаль с лесенкой → текст 15px (телефон 12px, короткие имена из `data-short`: Чехол · Латекс · Гель · Койра · Пена HR · Пружины · Основание). Следующая подсекция (факты) заходит на хвост пина: `margin-top: -24vh` (телефон −12vh), `z-index: 2`. После шрифтов и `load` — `ScrollTrigger.refresh()`. Перерисовка только при изменении кадра > 0.015 или размера. Скраб — не «анимация», при `reduced-motion` см. 6.5.

| Главы фильма | смена клипа: постер следующего под видео, `opacity` 250ms; автопереход каждые 4 с |
| Контур матраса в конфигураторе | пропорции 300ms `--ease-out` |
| Hover кнопок/карточек/ссылок | 400ms `--ease-out`; стрелка `translateX(4px)` |
| Тост | появление 250ms, уход 250ms через 2 с |

### 6.5 `prefers-reduced-motion: reduce`
Все `transition`/`animation` → `1ms`; `.reveal` виден сразу; строки hero на месте; сцена ELUNA **без пина**: статичный разложенный кадр (`img/eluna/seq720/f24.webp` как `<img>` с `alt` из `catalog.md` 16.6, все семь выносок видны, манифест — обычный абзац ниже); GSAP не грузится; счётчики показывают итог; видео не автоплеится, остаётся постер, главы переключаются кликом; карта без кольца; `scrollIntoView({ behavior: 'auto' })`; шапка не прячется; зерно и звёзды выключены. То же — когда `TIER === 'low'` и `navigator.connection.saveData`.

### 6.6 Бюджет производительности
`TIER`: `low`, если `saveData`, или `deviceMemory ≤ 4`, или `hardwareConcurrency ≤ 4`, или `reduced-motion`; иначе `mid` (телефон) / `high` (десктоп). Телефон, первый экран, до первого скролла — **≤ 600 КБ** (сжато):

## 7. Доступность и контроль качества

### 7.1 Доступность
- Контраст — §1.6: текст ≥ 7 : 1 на чёрном, ≥ 4,5 : 1 на молочном (мелкий ≥ 13px). Проверять **после** применения `opacity`-токенов на фактическом фоне (`--bg-3` панели).
- Цели касания ≥ 44 × 44px: кнопки шапки, чипы (36px высота + 8px внешнего поля = 44 зоны касания через `::before`), точки городов (44px невидимая зона), × в диалогах, сердце в карточке (36px + 4px поля).
- Порядок фокуса = порядок DOM = визуальный порядок: в зигзаге текст всегда раньше фото в DOM (фото переставляется `order`/`grid-column`), ничего не переставляется `tabindex > 0`.
- Roving tabindex (`tabindex="0"` у активного, `-1` у остальных, стрелки/`Home`/`End`): чипы категорий, сегменты модели и размера, образцы, чипы городов, главы фильма (`tablist`). Статичные чипы вариантов — `<li>`, в фокус не попадают.
- Диалоги: нативный `<dialog>` + `showModal()`, `aria-labelledby`, `Esc`, клик по подложке, «назад» (history), возврат фокуса, скролл страницы заперт. Меню телефона — тот же механизм.
- Заголовки: один `h1` (hero); `h2` — у каждой из секций 2–11; `h3` — категории, подблоки ELUNA (вступление `h2`, сцена/спек/модели/сравнение/размер — `h3`), главы фильма, FAQ-вопросы (`summary` содержит `h3`). Пропусков уровней нет.
- Ориентиры: `header`, `nav aria-label="Основное меню"`, `main`, `section aria-labelledby`, `footer`, `nav aria-label="Подвал"`.
- Изображения: `alt` из `copy.md` §13 и `catalog.md` §16.6; декор — `alt=""`/`aria-hidden`; холст сцены — `<figure aria-label="Матрас ELUNA в разрезе: семь слоёв расходятся по скроллу">` + скрытый `<ol>` слоёв; видео — `aria-label` главы и кнопка паузы с `aria-pressed`.
- Таблицы: `<caption>`, `th scope="col|row"`; сравнение на телефоне остаётся таблицей.
- Ссылки наружу: `rel="noopener"`, скрытый текст «откроется в новой вкладке»; WhatsApp — «откроется в WhatsApp». Телефоны — `tel:`, почта — `mailto:`.
- `lang="ru"`, `<title>` и `meta description` из `copy.md` §1, `theme-color #0C0C0E`, `viewport-fit=cover`, `prefers-reduced-motion` (§6.5), `prefers-contrast: more` → `--line` .28, `--ink-3` .8.
- Масштаб 200 % и ширина 320px — без наложений и горизонтальной прокрутки; `html { font-size: 100% }`, размеры в `px` только у линий/иконок, остальное масштабируется (`clamp` с `rem`-нижней границей допустим).
- Проходы: клавиатурой целиком (видимый фокус на каждом шаге), VoiceOver iOS по hero → каталог → ELUNA → контакты; Lighthouse Accessibility ≥ 95.

### 7.3 Чего не делать
- Коричневых, ореховых, бежевых заливок и «тёплого» градиента; фон только `--bg`-шкала и `#F4F0E8`.
- `#000` сплошняком и `#FFF` текстом (только `--ink` и hover-белый кнопки).
- Стоковых фото, AI-рендеров интерьеров, чужих картинок; фото крупнее 2× исходника; цветных фото рядом с дуотоном.
- Отзывов, звёзд рейтинга, «более 1000 клиентов», наград, «с 20XX года», числа мастеров, сроков по мебели — ничего, чего нет в брифе.
- Корзины, поиска, фильтров по цене, «купить в 1 клик», форм с полями, капчи, cookie-баннера, чат-виджетов, всплывающих окон при входе.
- Текста меньше 11px (кроме скрытого); `--ink-4` как текст; золота как текст на молочном; золота в заголовках.
- Второго гротеска (Inter/Manrope/Ysabeau) и третьей антиквы (Playfair/Noto); Unbounded вне блока ELUNA (кроме двух оговорённых подписей).
- Бегущих строк, автокаруселей, параллакса, бесконечных анимаций, звука, `overflow: hidden` на `body` при загрузке.
- Названий моделей из прежних макетов (SAVI, ELSEN, FLORIS, LUMO, CASE, KYOTO, CRYSTAL, MARKO) и «БСК».
- Рассрочки, «вынос старого матраса», медицинских обещаний («лечит», «исправляет осанку»).
- Формулировок BOCA/MONONOVA («комплектации объектов коммерческой недвижимости», «мебель вне времени»).
- Внешних CDN, Google Fonts, карт-виджетов, аналитики до решения заказчика.
