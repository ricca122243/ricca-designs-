# img/projects/ — обложки раздела «Проекты» (MANIFEST)

**Все изображения в этой папке — ИИ-визуализации, не реальные проекты.** На сайте под каждой обложкой стоит подпись «визуализация» (`projects.caption.viz`).

- Генерация: Higgsfield, модель `gpt_image_2`, 2k, исходник 3:4 (портрет) или 16:9 (широкий).
- Портрет обрезан до 4:5 (1200×1500) с запасом вокруг мебели. Широкий кадр обрезан до 16:10 (1920×1200).
- Экспорт: WebP q80, `method=6`, без метаданных. Уменьшенные версии: `-600` (600×750) для портретов, `-960` (960×600) для широких.
- Цвет: местами лёгкая нейтрализация (R чуть ниже, B чуть выше, насыщенность −6…−12 %), чтобы белые оставались молочно-нейтральными, без бурого оттенка. Если цвет не правился, так и указано.
- Размер `NN-name.webp` в спецификации CONTENT-V3 (1600×2000 / 2400×1500) больше фактического. Этот манифест главнее: файлы 1200×1500 и 1920×1200.


> **Правило для вёрстки (9 октября):** на сайте используем ТОЛЬКО файлы из таблицы «В папке». Сейчас это четыре обложки
> (p02-bedroom, p03-dining, p04-study, p08-media) и кадр ателье atelier-wide. Опенер раздела «Проекты» — p08-media (или p02),
> пока нет p01-living-wide. Слоты p01, p05, p06, p07 не показываем вовсе (без пустых рамок и заглушек); ссылки из «Для бизнеса»
> ведут на раздел «Проекты» целиком. Когда недостающие файлы появятся, их добавят в ту же сетку.
