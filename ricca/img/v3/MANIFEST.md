# img/v3 — ассеты нового сайта RICCA DESIGNS (v3)

Сайт в духе французского минимализма: молочно-белая основа (#FBFAF7), чёрный текст и тонкие линии; чёрные главы только для ELUNA, «Для бизнеса» и контактов/футера. Без коричневых заливок и тёплого отлива на фото. Все файлы ниже сделаны локально (PIL + numpy, Chromium для рендера SVG), без внешних сервисов. Шрифты для этой сборки — `ricca/css/fonts-v3.css` (описание в шапке файла).

> **Важно для заказчика:** все фотографии здесь — кадры из видео 478 × 850 и 513 × 640 (низкое разрешение, мягкие). Они прошли цветокоррекцию и аккуратный апскейл, но для «дорогого» сайта **нужны настоящие фото**: шоурум, 6–10 моделей на нейтральном фоне, фактуры тканей и кож крупно, производство — минимум 2000 px по длинной стороне, без фильтров Instagram. До их появления фото на сайте показываем сдержанно, в рамках и небольших форматах (по брифу).

## Фото: как грейдили и почему так

Цель — убрать жёлто-коричневый отлив (заказчик не любит коричневый), оставить естественные цвета (не ч/б), чуть поднять контраст. На молочной основе кадры проверены: диваны светло-серые/тауп, стены нейтральные, пол без рыжины — фото не «грязнят» белую страницу.

Пайплайн (`grade()` в скрипте, в линейном свете):
1. Частичный баланс белого «серый мир» — коэффициенты к среднему по каналам, применены на 45 % (hero) / 60 % (диваны).
2. Выборочное обесцвечивание тёплых оттенков: hue 7–67° (пик на 37°, оранжево-жёлто-коричневые) −72 % (hero) / −50 % (диваны), плавный спад к краям диапазона.
3. Общая насыщенность −12 %.
4. Контраст S-кривой +10 %, точка чёрного +2 %.
5. Едва заметный холодный сплит-тон в тенях (R −1,2 %, B +1,2 %) — тени не уходят в бурый; на белой основе это незаметно, но страхует от коричневого.

Результат по цифрам (среднее R−B по кадру, «+» = тёплый): диваны +29 → +5…+8; hero −3 → −2 (кадр изначально нейтральный, тёплыми были только шторы и пол: шторы R−B 14 → 10, остались натуральными тауп, не серыми).

**Про @2x.** Исходник hero — 513 px по ширине; правило «апскейл не более 2×» даёт максимум 1026 px, поэтому `hero-living.webp` (1024 w) — это уже предел, а `hero-living@2x.webp` (2048 w) **не делали** (был бы апскейл 4×). Показывать hero в рамке не шире ~512 CSS px на экранах 2× (так и задумано брифом). У диванов настоящий исходник — 478 × 850 (проверено: старые `img/showroom/*@2x.webp` — это тоже Lanczos-апскейлы, разница с нашим апскейлом < 1 уровня); `sofa-0N@2x.webp` — наш апскейл 2× после грейда, не «настоящие» 2×.

Подключение:
```html
<img src="img/v3/hero-living-512.webp" srcset="img/v3/hero-living-512.webp 513w, img/v3/hero-living.webp 1024w"
     sizes="(min-width: 1024px) 480px, 90vw" width="513" height="640" alt="Гостиная с угловым диваном RICCA" loading="eager" decoding="async">
<img src="img/v3/sofa-01.webp" srcset="img/v3/sofa-01.webp 1x, img/v3/sofa-01@2x.webp 2x" width="478" height="850" alt="…" loading="lazy">
```

## Фактуры тканей и кож (`tex-*.webp`, 512 × 512)

Тёмные нейтральные тайлы для чёрных глав (ELUNA, «Для бизнеса») и тёмных свотчей раздела тканей: средняя яркость 24–30 из 255, R−B ≈ −0,5 (ни намёка на коричневый), амплитуда рельефа ± 5–8 уровней, виньетка 10 % в углах (едва заметная). Сгенерированы процедурно (периодический шум, периодическое размытие), поэтому **бесшовны** при `background-repeat` — и работают как свотчи-карточки. Это условные фактуры-заглушки для раздела «Палитра тканей и кож»: заменить на макросъёмку реальных образцов, когда заказчик пришлёт.

```css
.swatch--boucle { background: #141415 url("img/v3/tex-boucle.webp") center / 256px repeat; } /* 256px — рельеф в 2 раза мельче */
```

## Логотип, OG, favicon

- `img/logo/rd-monogram.svg` — единственный `<path fill="currentColor">`. Инлайн в HTML он берёт цвет из CSS `color` — это основной способ: на белой основе чёрный, внутри чёрных глав `color: var(--milk)`. Проверено в Chromium: **белым на чёрном рендерится** инлайн с `color` и `rd-monogram-milk.svg`; внутри `<img>` currentColor не наследуется и монограмма всегда чёрная (на чёрной главе невидима) — поэтому для `<img>` есть две копии с явной заливкой: `rd-monogram-black.svg` и `rd-monogram-milk.svg`.
- `og-image-v3.jpg` 1200 × 630 — молочный, без фото и градиентов: чёрная монограмма, «RICCA DESIGNS» разреженными заглавными Montserrat, волосяная линия, подпись «АТЕЛЬЕ МЯГКОЙ МЕБЕЛИ • АЛМАТЫ».
- `favicon-v3.svg` + `favicon-v3-32.png` + `favicon-v3-180.png` — чёрная RD на молочной скруглённой плашке (читается на светлой и тёмной панели вкладок).
