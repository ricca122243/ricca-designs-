Документ для сборщиков нового сайта `ricca/` (статический, без сборки). Он описывает, **как выглядит и ведёт себя** сайт; **что на нём написано** — `content/CONTENT-V3.md` (ключи `раздел.ключ`), источники текстов — `content/catalog.md`, `content/copy.md`; **что правда** — `BRIEF.md` (раздел «НОВЫЙ САЙТ С НУЛЯ» и «УТОЧНЕНИЕ ЗАКАЗЧИКА»). Если документ и бриф расходятся — прав бриф. Если документ и контент-дек расходятся в тексте — прав контент-дек.

Статус: спецификация, по которой три сборщика делают три прототипа (см. `PANEL-BRIEF.md`). Числа — рабочие значения, их можно двигать на ±10 %, не ломая отношений между ними; токены, шрифты, факты, порядок секций и структура шапки/контактов/подвала не обсуждаются.

## 1. Палитра

Идея цвета: лист дорогой бумаги и чёрная тушь. Два мира — **белая страница** (`:root`) и **чёрная глава** (`.chapter--noir`), в каждом свой набор одинаково названных токенов, поэтому компоненты переезжают между мирами без правок.

### 1.1 Молочно-белая основа (страница)

Молочный — не кремовый и не бежевый: чуть тёплый белый, на котором чёрный текст выглядит как печать, а не как экран. Три уровня бумаги + линии.

```css
:root {
  --paper:    #F7F5F0;   /* страница. Молочно-белый: теплее #FFF, но без желтизны */
  --paper-2:  #F1EEE8;   /* панели, плиты спек-блоков, паспарту у рамок, полоса клиентов */
  --paper-3:  #EAE6DF;   /* чипы, hover панелей, фон плейсхолдера обложки */
  --line:     rgba(17,17,17,.12);   /* волосяные линии: разделители, рамки фото и кнопок-контуров в покое */
  --line-2:   rgba(17,17,17,.30);   /* активная рамка, hover контура, рамка рамы фото */
  --line-3:   rgba(17,17,17,.06);   /* деления внутри таблиц и списков */
  --shadow:   none;                 /* теней на белом нет вообще; диалоги отделяются рамкой и подложкой */
}
body { background: var(--paper); color: var(--ink-2); }
```

Что разрешено как «глубина» на белом: только второй тон бумаги (`--paper-2`) с резкой кромкой и волосяные линии. Виньетки, зерно, градиенты, тени — запрещены на белом.

### 1.2 Чёрная тушь (текст на белом)

```css
:root {
  --ink:    #111111;               /* заголовки, вордмарк, цены, текст-ссылки, кнопка-заливка. 17,3 : 1 на --paper */
  --ink-2:  rgba(17,17,17,.78);    /* основной текст, лиды, паспорт dd. 9,1 : 1 на --paper, 8,3 : 1 на --paper-3 */
  --ink-3:  rgba(17,17,17,.72);    /* капс-лейблы, подписи, меню в покое. 7,3 : 1 на --paper, 6,8 : 1 на --paper-3 */
  --ink-4:  rgba(17,17,17,.26);    /* только декор: номера глав-водяные знаки, пунктир, плейсхолдер. 1,8 : 1 — не для чтения */
}
h1, h2, h3, .price, .wordmark { color: var(--ink); }
```

«Дорогой чёрный» — `#111111`, не `#000`: на бумаге `#000` выглядит как дыра. `#000` не используется нигде, кроме hover у чёрной кнопки (`#000` — единственное место).

### 1.3 Чёрные главы `.chapter--noir`

Три главы: `#eluna` (со своей средой, §1.5), `#business`, `#contacts` + `footer`. Объявляют те же имена токенов, поэтому кнопки, eyebrow, линии, паспорт, бейджи работают без вторых классов.

```css
.chapter--noir {
  --paper:   #0C0C0E;   /* глубокий чёрный, не #000: на OLED не сливается с рамкой телефона */
  --paper-2: #141416;   /* панели, карточки, кнопка «Задать вопрос» (как плашка в макете: чуть светлее фона) */
  --paper-3: #1C1C1F;   /* hover панели, активный чип, липкая колонка таблицы */
  --ink:     #F7F5F0;   /* молочный текст = цвет страницы. 17,9 : 1 */
  --ink-2:   rgba(247,245,240,.78);   /* текст, лиды. 11,0 : 1 на --paper, 9,9 : 1 на --paper-3 */
  --ink-3:   rgba(247,245,240,.68);   /* подписи, лейблы. 8,4 : 1 на --paper, 7,8 : 1 на --paper-3 */
  --ink-4:   rgba(247,245,240,.30);   /* декор */
  --line:    rgba(247,245,240,.14);   /* линия над контактами в макете заметна — не .08 */
  --line-2:  rgba(247,245,240,.30);
  --line-3:  rgba(247,245,240,.06);
  background: var(--paper); color: var(--ink-2);
}
```

Кромка между белой страницей и чёрной главой — **резкая**, без градиентов и «затемнений»: чёрная глава начинается как перевёрнутая страница книги (как белые спек-блоки у Apple, только наоборот). Отступы внутри главы — те же `--section`, чёрное не «съедает» воздух. Доля чёрного по высоте страницы — 25–35 % (ELUNA ≈ 5 экранов, бизнес ≈ 1, контакты + подвал ≈ 1,5); больше — значит основа перестала быть белой.

### 1.4 Золото — один hex, только в чёрных главах

```css
.chapter--noir { --gold: #C8A86B; }   /* 8,6 : 1 на #0C0C0E; 7,5 : 1 на #1C1C1F — читается как текст на чёрном */
:root { --gold: var(--ink); }          /* на белой странице «золотые» роли (если класс случайно попал) рисуются чёрным */
```

| Разрешено (только `.chapter--noir`) | Запрещено |
|---|---|
| Основной телефон в контактах и подвале — текст, как в refs/04 | Любое золото на белой странице: контраст `#C8A86B` на `#F7F5F0` — 2,1 : 1; даже как линия — нет (на белом линии чёрные) |
| Бейдж «Выбор ELUNA» (текст + рамка 1px `rgba(200,168,107,.6)`) | Заголовки, лиды, абзацы |
| Волосяная линия 1px под ценой Prime и над строкой цены в таблице сравнения | Заливки кнопок, фоны, градиенты, свечение |
| Слово «тишина» в манифесте ELUNA (цитата стиля ELUNA — единственное золотое слово в тексте) | Иконки (они молочные) |
| Точки-разделители eyebrow внутри `#eluna` (3 × 3px) | `::selection` и `:focus-visible` — на чёрном они молочные, не золотые (золото остаётся редким) |

### 1.5 Среда ELUNA — космос только внутри `#eluna`

Блок ELUNA — «другой продукт внутри сайта»: чёрная глава с дополнительными переменными на самой секции, не на `:root`.

```css
.eluna {
  --paper: #08090D;               /* чуть холоднее и глубже остальных чёрных глав; это же значение — заливка lighten у холста (§6.3) */
  --e-warm: 255, 243, 226;        /* тёплый прожектор (луна) — из styles.css сайта ELUNA */
  --e-cool: 196, 208, 255;        /* холодная подсветка краёв */
  --e-font: 'Unbounded', 'Montserrat', sans-serif;
  position: relative; isolation: isolate; overflow: hidden;
}
```

Что из космоса ELUNA разрешено — и только здесь:
1. **Слабое звёздное поле**: один `<canvas>` на секцию (не `fixed`), плотность 1 звезда на 9 000 px² десктоп / 14 000 телефон (вдвое реже, чем у ELUNA), радиус 0,3–1,4px, альфа 0,18–0,6; без мерцания и метеоров; `reduced-motion` — статично; на `TIER === 'low'` выключено.
2. **Свечение луны**: `radial-gradient(closest-side at 84% 12%, rgba(var(--e-warm), .10), transparent 70%)` на вступлении; сама луна `img/eluna/moon-hd-1280.webp` — декор вступления только на десктопе (`loading="lazy"`, ширина ≤ 42vw, обрезана краем секции); на телефоне луны нет. WebGL-шар ELUNA не переносится.
3. **Unbounded** для заголовков блока, названий моделей, цен и цифр фактов; текст внутри блока — Montserrat (Inter не подключаем — второй гротеск не нужен).
4. **Виньетка** `radial-gradient(80% 60% at 50% 40%, transparent, rgba(0,0,0,.45))` под сценой.
5. Белый спек-блок `#eluna-spec` внутри главы (§5.5.4) — **возвращает цвета страницы** (`:root`-токены), без звёзд: это «белая страница характеристик» как у Apple.

Снаружи `#eluna` нет звёзд, луны и Unbounded — кроме двух подписей: слово «ELUNA» в бейдже «Новинка · ELUNA» навигации по каталогу (§5.3) и в ссылке «Сайт ELUNA» подвала (Unbounded 500, 1em).

## 2. Типографика

Шрифты только локально: `fonts/fonts.css` (Cormorant, Montserrat — остальные семейства файла не подключать) + `css/fonts-eluna.css` (Unbounded). Playfair, Noto Serif Display, Manrope, Ysabeau, Inter на новом сайте **не используются**.

```css
:root {
  --serif: 'Cormorant', 'Garamond', Georgia, serif;
  --sans:  'Montserrat', system-ui, -apple-system, 'Segoe UI', Roboto, Arial, sans-serif;
  --e-font: 'Unbounded', var(--sans);
}
body { font: 400 17px/1.6 var(--sans); -webkit-font-smoothing: antialiased; }
```

Предзагрузка на первом экране — ровно четыре файла: `cormorant-cyrillic-var-normal`, `cormorant-cyrillic-var-italic`, `montserrat-cyrillic-var-normal`, `montserrat-latin-var-normal`. Латиница Cormorant подгрузится по `unicode-range` сама; Unbounded — когда `#eluna` в 75 % от вьюпорта (`document.fonts.load('500 1em Unbounded')` из наблюдателя секции).

### 2.1 Cormorant — дисплейная антиква RICCA

На белом Cormorant 400 выглядит так, как на refs/06 — это и есть эталон. На чёрных главах заголовков Cormorant мало (только `#business` — нет, там Montserrat caps по refs/05; `#contacts` — h2 Cormorant 400 → 450 через `font-variation-settings: 'wght' 450`, потому что светлый тонкий текст на чёрном визуально худеет).

| Роль | 1440 | 390 | Начертание | Интерлиньяж / трекинг |
|---|---|---|---|---|
| `h1` hero | 128px (`clamp(60px, 8.6vw, 128px)`) | 60px | 400; строка-акцент — italic 400 | 0,96 / −0,015em |
| `h2` секция | 72px (`clamp(42px, 4.9vw, 72px)`) | 42px | 400 | 1,02 / −0,01em |
| `h3` подраздел, заголовок категории, проекта | 40px (`clamp(30px, 2.8vw, 40px)`) | 30px | 400 | 1,1 / 0 |
| Тезис / statement | 44px (`clamp(28px, 3vw, 44px)`) | 28px | italic 400 | 1,2 / 0 |
| Цифра-факт RICCA («3 года», «5 шагов») | 56px | 40px | 500, `lining-nums` | 1 / 0 |
| Номер главы-водяной знак («02») | 160px | 96px | 400, `--ink-4` | 1 / −0,02em |
| Подпись к фото / обложке («01 — Гостиная») | 15px | 14px | italic 500 | 1,4 / 0,01em |
| Вордмарки клиентов | 24px | 20px | 500 | 1,2 / 0,01em |

Правила:
- Курсив — одна строка или одно-два слова в заголовке (`<em>`): «по мерке», «и как это заказать», «руками», «примерку». Не больше одного курсивного акцента на заголовок и не в каждом заголовке подряд: hero, 2–3 секции. В ELUNA курсива нет (там Unbounded).
- Строки hero переносятся вручную `<br>`: «Мебель / *по мерке* / вашего дома»; вторая строка сдвинута вправо на 2 колонки (desktop) / 24px (phone) — ритм refs/06. На 390 кегль 60px помещает самую длинную строку «вашего дома» в 350px.
- Cormorant по умолчанию даёт старостильные цифры → на числа в антикве `font-variant-numeric: lining-nums tabular-nums`.
- Минимальный кегль Cormorant — 14px (подписи). Для подписей меньше — Montserrat.
- Вес на белом — 400 всегда; 500 — только цифры-факты и подписи italic.

### 2.4 Цифры, цены и знак ₸ — проверено по cmap локальных woff2

- Знак **₸ (U+20B8) есть только в `Unbounded-300/500`**. В локальных подмножествах Montserrat, Cormorant и `fonts/site/*` его **нет** — браузер подставит системный шрифт, и знак выпадет из строки. Поэтому:
  - все цены ELUNA — целиком в Unbounded (карточки, таблица, конфигуратор, липкая плашка);
  - единственная цена вне ELUNA — в FAQ («от 125 000 ₸») — оборачивается `<span class="tenge">₸</span>` с `.tenge { font-family: var(--e-font); font-weight: 300; font-size: .92em; }`;
  - **[TODO]** при доступе к сети собрать подмножество Montserrat с U+20B8 (`pyftsubset … --unicodes="U+0000-00FF,U+0400-045F,U+2000-206F,U+20B8"`) и убрать костыль.
- Табличные цифры там, где числа стоят колонкой или меняются (цены, конфигуратор, счётчики, телефоны): `font-variant-numeric: tabular-nums`.
- Формат: разряды через узкий неразрывный пробел `&#8239;` («125 000 ₸», «1 200»), перед ₸ — `&nbsp;`. Старая цена — `<s class="price-old">` `--ink-3`, `text-decoration-thickness: 1px`, рядом скрытое «старая цена». Диапазон — короткое тире без пробелов («280–300 мм»); размеры — «1600 × 2000 мм» (×, U+00D7). Телефоны: `+7&nbsp;(708)&nbsp;480-20-47`.

### 2.5 Типографика текста (обязательна в разметке)
«Ёлочки», внутри — „лапки“; длинное тире с пробелами (` — `, перед тире `&nbsp;`); диапазоны коротким тире; `&nbsp;` после предлогов и союзов в 1–2 буквы, в «3 года», «5 лет», «ул. Алишера Навои», «208/2», «RICCA DESIGNS», «Eluna Prime»; буква «ё»; точка в конце заголовка не ставится (кроме заголовков из двух предложений — «ELUNA. Наш матрас.»). Eyebrow в HTML обычным регистром, `text-transform` в CSS. Функция `typo()` из контент-дека §27.4 — для новых строк.

## 3. Сетка, отступы, формы

```css
:root {
  --container: 1360px;
  --gutter: clamp(20px, 5vw, 72px);     /* 390 → 20px; 1440 → 40px (1360 = 1440 − 2·40); ≥ 1600 → 72px */
  --col-gap: 24px;                      /* 12 колонок: (1360 − 11·24) / 12 = 89,3px */
  --sp-1: 8px; --sp-2: 16px; --sp-3: 24px; --sp-4: 40px; --sp-5: 64px; --sp-6: 96px; --sp-7: 144px;
  --section: clamp(80px, 10vw, 144px);  /* вертикальный отступ секции: 390 → 80px; 1440 → 144px */
  --section-tight: clamp(56px, 6vw, 96px);
  --radius: 0;                          /* углов нет: ни у кнопок, ни у карточек, ни у рамок — французский минимализм прямоуголен */
  --nav-h: 72px;                        /* телефон 60px */
}
.container { width: min(100% - 2 * var(--gutter), var(--container)); margin-inline: auto; }
.grid { display: grid; grid-template-columns: repeat(12, 1fr); column-gap: var(--col-gap); }
```

Брейкпоинты: `≤ 599` телефон · `600–899` планшет · `≥ 900` десктоп. Проверка макетов — 390 × 844 (трафик из Instagram) и 1440 × 900. Горизонтальной прокрутки нет на ширинах 320–1920: `document.documentElement.scrollWidth === innerWidth`.

| Ширина | Контейнер | Колонки | Типовые доли |
|---|---|---|---|
| 1440 | 1360 | 12, gap 24 | hero: текст 7/12, обложка 4/12 со сдвигом на 1; категория: текст 5/12, фото 5/12 через 1 (зигзаг); проекты: 7/12 + 4/12 чередуясь; карточки ELUNA 3 × 3/12 + Royal 3/12; таблица 10/12; FAQ 8/12 по центру |
| 1024 | 100 % − 2·48 | 12 | текст 6/12, фото 6/12 |
| 600–899 | 100 % − 2·32 | 6 | зигзаг → колонка: заголовок, фото 6/6, паспорт 6/6; проекты 2 × 3/6; карточки ELUNA 2 × 3/6 |
| 390 | 350 (gutter 20) | 4 | всё в одну колонку; карточки ELUNA — лента `scroll-snap` (старт на Prime) + Royal панелью ниже; таблица сравнения — лента с липкой первой колонкой |

Вертикальный ритм секции: номер + eyebrow → 16px → заголовок → 24px → лид → 40px → контент. Между блоками внутри секции `--sp-5`, между секциями `--section`. При входе в чёрную главу и выходе из неё отступ **тот же** — смена цвета не заменяет воздух.

Формы и линии:
- Углы 0 везде. Круглое только: счётчик «Подборки» (18px) и точки в eyebrow (3px).
- Рамка фото и обложки — 1px `--line-2` с паспарту 12px `--paper-2` (как на refs/06): фото лежит «под стеклом», даже слабый кадр выглядит экспонатом. Обложки проектов (ИИ, хорошего качества) — без паспарту, рамка 1px `--line` вплотную.
- Волосяные линии `hr.rule` — 1px `--line`; каждая секция на белом начинается линией на всю ширину контейнера с номером слева и названием главы справа (колонтитул): `02 ———————————— Проекты`.
- Тени — нигде. Диалоги и панели отделяются подложкой `rgba(17,17,17,.4)` и рамкой 1px `--line-2`.

## 6. Движение

Принцип: движение на белой странице — **почти незаметное**, как перелистывание бумаги: вещи появляются на месте, ничего не летает, не пружинит и не крутится. Единственная «большая» сцена — ELUNA внутри чёрной главы. Всё движение построено на трёх переменных и одном классе:

```css
:root {
  --ease-out: cubic-bezier(.16, 1, .3, 1);   /* всё, что появляется */
  --ease-in:  cubic-bezier(.7, 0, .84, 0);    /* всё, что уходит (шапка, тост, диалог) */
  --dur: 700ms; --dur-fast: 300ms; --dur-slow: 1100ms;
}
.reveal { opacity: 0; transform: translateY(24px); transition: opacity var(--dur) var(--ease-out), transform var(--dur) var(--ease-out); transition-delay: var(--d, 0ms); }
.reveal.is-in { opacity: 1; transform: none; }
@media (prefers-reduced-motion: reduce) { .reveal { opacity: 1; transform: none; transition: none; } }
```

JS: GSAP 3.15 + ScrollTrigger из `vendor/` (локально, без CDN) подключаются **только** для сцены ELUNA и грузятся отложенно (§6.6). Всё остальное — `IntersectionObserver` + CSS-переходы; без GSAP страница полностью работает.

### 6.1 Появление по скроллу `.reveal`

- Один `IntersectionObserver` на все `.reveal`: `threshold: 0`, `rootMargin: '0px 0px -12% 0px'` (элемент начинает появляться, когда его верх прошёл 12 % от низа экрана). Срабатывает один раз, `unobserve` после входа; при скролле вверх ничего не прячется.
- Лесенка внутри группы (`[data-stagger]`): дочерним `.reveal` выставляется `--d: i × 80ms`, максимум 6 ступеней (далее — 480ms для всех); строки навигации каталога — 60ms; обложки проектов — 80ms; карточки ELUNA — 100ms (Prime — последней, +60ms сверху: внимание приходит к флагману).
- Фото и обложки: вместо `translateY` — `opacity 0 → 1` и `scale(1.02) → 1` за 900ms (`.reveal--img`); рамка и подпись — обычный `.reveal` с `--d: 200ms`.
- Элементы, которые при загрузке уже в экране (hero, шапка), **не** получают `.reveal` — страница не должна «собираться» на глазах; `.reveal` ставится начиная со второй секции.
- Чёрные главы: та же механика; дополнительно кромка главы не анимируется (резкая смена цвета — часть ритма «перевёрнутой страницы»).

### 6.2 Первый экран

Последовательность при загрузке (без скролла, запускается по `DOMContentLoaded` + `document.fonts.ready`, но не позже 600ms — если шрифты не успели, идём с fallback и `font-display: swap` подменит):

| t | Элемент | Движение |
|---|---|---|
| 0 | eyebrow + линия | `opacity 0 → 1`, 500ms |
| 80ms | строка 1 «Мебель» | каждая строка `h1` — `<span class="line"><span>…</span></span>`, внешний `overflow: clip`, внутренний `translateY(110%) → 0`, 900ms `--ease-out` |
| 200ms | строка 2 «*по мерке*» | то же |
| 320ms | строка 3 «вашего дома» | то же |
| 500ms | лид, кнопки, «Каталог →» | `.reveal` стопкой с `--d` 0 / 80 / 160ms |
| 300ms | обложка / фото в рамке | `opacity 0 → 1`, `scale(1.02) → 1`, 1 100ms; подпись +200ms |
| 600ms | адресная строка с пунктиром | `opacity`, 500ms; «Листайте» — без мигания и стрелок-«баунсов» |

`reduced-motion`: всё видно сразу, `h1` без обрезки (`overflow: visible`). На телефоне последовательность та же, обложка ниже сгиба — просто `.reveal--img`.

### 6.3 Сцена ELUNA `#eluna-stage` — пин и кадры

Единственное место с GSAP. Сцена — `position: relative` блок высотой `100vh` (`100svh` на телефоне), который ScrollTrigger пинит; внутри — `<canvas id="seq">` с 24 кадрами разреза матраса, выноски слоёв, тексты фаз.

```js
gsap.registerPlugin(ScrollTrigger);
ScrollTrigger.config({ ignoreMobileResize: true });          // адресная строка телефона не дёргает пин
const D = matchMedia('(min-width: 900px)').matches;
const tl = gsap.timeline({ defaults: { ease: 'none' }, onUpdate: render,
  scrollTrigger: { trigger: stage, start: 'top top', end: D ? '+=170%' : '+=120%',
                   pin: true, scrub: D ? 0.5 : 0.35, anticipatePin: 1, invalidateOnRefresh: true,
                   onUpdate: (st) => setPhase(st.progress) } });
```

Длина пина: **170 % высоты экрана на десктопе, 120 % на телефоне** (меньше — сцена «проскакивает», больше — на телефоне трафик из Instagram устаёт листать). Якорная ссылка на `#eluna-stage` ведёт в начало пина (`scroll-margin-top: 0`).

Фазы по прогрессу (`S` — объект состояния, `render()` пишет только `transform`/`opacity` и рисует холст):

| Прогресс | Фаза | Что происходит |
|---|---|---|
| 0 → 0,08 | вход | вступительный текст главы (5.1) уходит вверх на 24px и гаснет; собранный матрас (кадр `f01`) проявляется в центре `opacity 0 → 1`, `scale .96 → 1` |
| 0,08 → 0,62 | **раскрытие** | индекс кадра `f = 1 + progress' × 23` (линейно, `progress'` нормирован на фазу); между соседними кадрами — кросс-фейд по дробной части (как в `main.js` ELUNA: `drawImage(a)`, затем `b` с `globalAlpha = t`); выноски слоёв появляются порогами: слой `i` — при `f ≥ 3 + 3i` (`opacity 0 → 1`, `translateX(−8px → 0)`, 350ms), активная выноска — `--ink`, остальные `--ink-3` |
| 0,62 → 0,80 | фокус | кадр `f24` (полностью раскрыт) стоит; заголовок «Семь слоёв. / Одно ощущение.» виден; на десктопе матрас сдвигается влево на 6 % под выноски |
| 0,80 → 1 | выход | выноски гаснут, холст `scale 1 → .92`, `opacity 1 → .35`; поверх — манифест `eluna.manifesto` (`opacity 0 → 1`, `translateY(16px → 0)`); после `progress > 0,96` сцена отпускается и следом идут факты 5.3 |

Тексты фаз — **не в scrub-таймлайне**, а через `setPhase()` с `gsap.to(…, { autoAlpha, overwrite: true })`: уходящий гаснет за 200ms, входящий появляется через 220ms — на экране никогда нет двух текстов (на телефоне весь переход ≈ 100px скролла, в scrub они бы наехали).

Холст:
- Кадры: десктоп и планшет — `img/eluna/seq/f01…f24.webp` (1920 × 1080, ≈ 75 КБ/кадр, 1,8 МБ); телефон — `seq720/` (1280 × 720, ≈ 57 КБ/кадр, 1,4 МБ). Выбор по `innerWidth < 900 || devicePixelRatio × innerWidth < 1400`. Ретина 1440 × 2: кадр 1920 отображается на ширине ≤ 960 css-px (сцена 8/12) — 1× на ретине, достаточно; `seq2560` сайта ELUNA не переносится.
- Геометрия: кадр вписан `contain` в область 82 % ширины на телефоне (смещён влево на 12 % ширины, выноски справа) и 7/12 контейнера на десктопе; холст в css-px = область × `min(devicePixelRatio, 2)`.
- Композитинг, как у ELUNA: после кадров `globalCompositeOperation = 'lighten'` заливка `#08090D` (= `--paper` главы: чёрный фон кадра сливается с главой, кромки кадра нет), затем `destination-in` с радиальной виньеткой (§1.5, п. 4). Перерисовка только при смене кадра на > 0,015 или размера (`seqDirty`).
- Загрузка: начинается, когда `#eluna` входит в `rootMargin: '75% 0px'` (на экран раньше, чем виден), по 3 изображения параллельно, порядок — `f01`, `f24`, `f12`, затем остальные (первый, последний и середина дают сцену при любом прогрессе); `img.decode()` перед записью в массив; до прихода кадра рисуется ближайший загруженный (`nearestFrame`). Если к моменту входа в пин загружено < 3 кадров — пин всё равно работает, сцена догоняет. Звёзды (§1.5) — отдельный холст, `setVisible(false)` вне экрана.
- Сцена вне экрана (`IntersectionObserver`, `threshold: 0`, важна последняя запись пачки — пин переподвешивает узел): `render()` не вызывается, звёзды стоят.
- `visibilitychange` → перерисовка при возврате на вкладку.

Доступность сцены: `<canvas role="img" aria-label="Разрез матраса ELUNA: семь слоёв от чехла до основания">`; выноски — настоящий `<ol>` в DOM (читается ридером как список слоёв независимо от анимации); перед сценой — `.skip-link` «Пропустить сцену» → `#eluna-spec`, видна при фокусе; клавиатурный скролл (пробел, стрелки, PgDn) двигает пин как обычный скролл.

**Reduced-motion / низкий уровень (`TIER === 'low'`: `deviceMemory ≤ 2` или `hardwareConcurrency ≤ 2` или `saveData`)**: GSAP не грузится, пина нет; сцена — обычная секция: один `<img>` `img/eluna/mattress-layers.webp` (статичный раскрытый разрез; на телефоне `mattress-layers-walnut-800.webp`) в той же области, `<ol>` выносок виден целиком списком справа/снизу, манифест — просто абзац после. Звёзд нет, луна статична (десктоп) или отсутствует (телефон). Кадры `seq` не загружаются вовсе — экономия 1,4–1,8 МБ.

### 6.5 Reduced motion — сводно

`@media (prefers-reduced-motion: reduce)` и `TIER === 'low'` (второе — только для сцены и звёзд):

| Компонент | Поведение |
|---|---|
| `.reveal`, лесенки, hero-строки | видимы сразу, переходов нет |
| Сцена ELUNA | статичный разрез `mattress-layers.webp`, список слоёв, без пина и GSAP |
| Звёзды, луна | звёзд нет; луна — статичная картинка (десктоп) |
| Счётчики | сразу конечное значение |

| `scroll-behavior` | `auto` |
| Hover-переходы цвета | допустимы (не движение), оставляем |

### 6.6 Бюджет производительности

Цели (телефон, 4G, Moto G-класс): первый экран ≤ 600 КБ передано, LCP ≤ 2,5 с, CLS = 0, INP ≤ 200ms; десктоп: LCP ≤ 1,8 с. Lighthouse Performance ≥ 90 на обоих.

| Ресурс первого экрана (телефон) | Бюджет | Как |
|---|---|---|
| HTML | ≤ 60 КБ | одна страница; `wa.*`-тексты в `data-wa`, не дубли в JS |
| CSS | ≤ 40 КБ | один файл, без фреймворков; критического инлайна нет (один файл грузится быстрее двух запросов) |

Отложенное:
- `vendor/gsap.min.js` (73 КБ) + `ScrollTrigger.min.js` (45 КБ) и `js/eluna.js` — `<script defer>` вставляется динамически, когда `#eluna` в `rootMargin: '100% 0px'` (за экран до главы) и не `reduced-motion`/`low`; до этого глава отображается статично (как в §6.3 fallback), после инициализации `ScrollTrigger.refresh()`.
- Unbounded 300 + 500 (76 КБ) — `document.fonts.load` при `rootMargin: '75% 0px'` на `#eluna`.
- Кадры `seq` — §6.3, 75 % root margin; не грузятся на `low`/`reduced-motion`.
- Все остальные `<img>` — `loading="lazy" decoding="async"` с `width/height`; обложки проектов `srcset` 800w/1600w и `sizes` по колонке (`(max-width: 599px) 100vw, (max-width: 899px) 50vw, 430px` для 4:5; `…, 780px` для 3:2).
- Видео: один `<video preload="none">`; `<source>` меняется по выбору главы; `webm` первым, `mp4` вторым; постеры из `img/mono`. Общий вес 10 клипов 1,3 МБ (webm) — но одновременно в памяти один.
- Карта `kz-map-1280.webp` на телефоне / `2080` на десктопе — lazy.
- `mattress-layers*.webp` (fallback сцены) грузится только в fallback.

Правила отрисовки: анимируются только `transform` и `opacity`; `will-change` — только у холста сцены и строк hero на время анимации (снимается после); никаких `box-shadow`/`filter` в переходах; `content-visibility: auto` + `contain-intrinsic-size` у секций ниже сгиба (кроме `#eluna` — пин несовместим). `backdrop-filter` не используется нигде.

Проверка (обязательна перед сдачей прототипа): `node scratchpad/shoot.js http://localhost:PORT/ricca/ out` → 1440 × 900 и 390 × 844, первый экран и вся страница, JSON без `console.errors` и с `overflow: false`; Lighthouse mobile/desktop; Network-вкладка с троттлингом «Fast 3G»: первый экран ≤ 600 КБ, `seq` не грузится до подхода к ELUNA.

### 7.2 Цели касания и клавиатура

- Все кликабельные ≥ 44 × 44 css-px на телефоне (кнопки 56px, чипы 36px + зона `::before` 44px, × в диалогах 44px, точки городов — кнопка 44px вокруг точки 6px, сердца в карточках 36px → 44px зона, ссылки подвала — строка 20px интервала + `padding-block: 8px` = 44px). Расстояние между соседними целями ≥ 8px.
- Порядок фокуса = визуальный порядок DOM: шапка (локап → меню → Подборка → WhatsApp) → hero (кнопки слева направо) → … Внутри зигзага текст идёт раньше фото в DOM, независимо от стороны (`order` только в CSS).
- Roving tabindex (один `tabindex="0"` в группе, остальные `−1`, стрелки, `Home/End`): образцы фактур (`radiogroup`), сегменты конфигуратора (модель, размер), чипы городов, список глав фильма (`tablist` — `←/→`, `Enter/Space` активирует), липкие чипы каталога (это ссылки — обычный Tab, без roving).
- Диалоги (`<dialog>`): фокус при открытии — на первый интерактивный элемент тела (не на ×); ловушка фокуса нативная; `Esc`, подложка, кнопка «Закрыть», жест «назад» — все закрывают; фокус возвращается на открывший элемент; `aria-labelledby`; `inert` на остальной странице (полифилл не нужен — нативный `showModal`).
- Липкая плашка — в конце DOM, но `aria-hidden="true"` пока скрыта и `tabindex="-1"` у её кнопок (не ловить фокус за экраном).
- Scrollspy не меняет фокус. Плавный скролл по якорю переносит фокус на целевую секцию (`tabindex="-1"` + `focus({ preventScroll: true })`) — ридер продолжает чтение с нужного места.
- Нет `title`-тултипов как единственного источника смысла; нет клавиатурных ловушек в лентах `overflow-x` (они прокручиваются Tab-ом по содержимому).
