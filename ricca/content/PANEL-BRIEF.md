# RICCA DESIGNS — бриф для трёх сборщиков прототипов (панель A / B / C)

Три прототипа одного сайта, собранных по одной системе — `content/DESIGN-V3.md` (токены, шрифты, сетка, компоненты, карта страницы, движение, приёмка) и `content/CONTENT-V3.md` (все тексты и `wa.*`-сообщения). Варианты отличаются **арт-дирекцией внутри системы**, а не системой. Заказчик выберет один; победитель станет `ricca/index.html`.

## Что одинаково у всех трёх (не обсуждается)

- **Основа молочно-белая** `#F7F5F0`, тушь `#111`; чёрный только дополняет: ровно три чёрные главы — ELUNA, «Для бизнеса», контакты + подвал. Коричневого нет. Золото `#C8A86B` — только внутри чёрных глав (основной телефон, «Выбор ELUNA»).
- Шрифты: Cormorant (заголовки RICCA, с курсивным акцентом), Montserrat (вордмарк, меню, лейблы, текст), Unbounded — только внутри `#eluna`. Локально, из `fonts/`.
- **Шапка и подвал — как в макете заказчика** (`refs/03`, `refs/04`): локап RD + «RICCA / DESIGNS • ALMATY»; без поиска и корзины; сердце = «Подборка». Контакты дословно: ОСНОВНОЙ / WHATSAPP золотом, ОТДЕЛ ЗАКАЗОВ, EMAIL, АДРЕС ШОУРУМА, график, «ЗАДАТЬ ВОПРОС», иконки WhatsApp · Instagram · 2ГИС. Подвал — три колонки дословно. Это чёрная глава у всех трёх.
- Первый экран: «Мебель / *по мерке* / вашего дома» антиквой (как на `refs/06`, на белом), чёрная `--fill` + контурная + тихая «Каталог».
- Порядок секций §5 DESIGN-V3 (DOM: … Доставка → FAQ → Контакты → Подвал); «Проекты» с ИИ-обложками (`img/projects/`, пока нет — плейсхолдеры тех же размеров), подписи с словом «визуализация».
- ELUNA — чёрная глава с пином и 24 кадрами, белый спек-блок внутри, 4 модели с реальными ценами (Prime — «Выбор ELUNA», Royal отдельно), таблица, конфигуратор, «≈ ₸ за ночь».
- Факты только из брифа; каждая кнопка — WhatsApp с готовым текстом; липкая плашка на телефоне; никаких форм, отзывов, цифр, наград.
- Приёмка — чек-лист §7.4 DESIGN-V3: `shoot.js` 1440/390 без ошибок и overflow, контраст ≥ 7 : 1 для текста, первый экран ≤ 600 КБ, Lighthouse A11y 100.
- Папка: `ricca/_panel/{a-maison-blanche|b-galerie|c-chapitres}/index.html`, общие `css/tokens.css` из §8.1, ассеты по `../../img/…`, `../../fonts/…`, `../../video/…`, `../../vendor/…`. Сервер: `python3 -m http.server` из корня репозитория. Без коммитов.

## Чем отличаются — что именно исследовать

### A — «Maison Blanche» (типографика ведёт)
Парижский модный дом: страница читается как номер журнала. **Cormorant огромный** — h1 по верхней границе `clamp` (128px на 1440, на телефоне 60–64px), курсивные акценты в большинстве h2 (по одному слову), **нумерованные главы** с колонтитулами «02 ———— Проекты» и водяными номерами в углах, волосяные линии как главный графический элемент. Обложки и фото — **маленькие и точные**: 4/12 и меньше, всегда в рамке с паспарту, подпись курсивом; проекты — список-оглавление (номер, комната, что сделали) с небольшой обложкой справа, а не стена картинок. Много воздуха: `--section` по верхней границе, ширина текста 30em. Паспорт категорий — как таблица содержания книги с отточием. ELUNA в этом варианте — «вкладка другого журнала»: Unbounded только там, чёрная глава лаконичная. Риск, который нужно проверить: не стала ли страница «пустой» на телефоне — заголовки должны держать экран сами.

### B — «Galerie» (изображение ведёт)
Белые стены галереи, обложки проектов — **экспонаты в рамках**. Асимметричная галерейная сетка: 7/12 ↔ 4/12 ↔ 5/12 со сдвигами по вертикали (обложка 02 начинается на 120px ниже 01), большие поля между экспонатами, никаких карточек-плиток. Подписи — **как музейные таблички**: Montserrat 11px caps «01 — ГОСТИНАЯ», под ней Cormorant italic мелко «угловой диван и пуф по размеру комнаты · визуализация»; таблички стоят под рамкой слева. Hero — одна крупная обложка 01 (до 5/12) и заголовок, остальное тише. Категории каталога — тоже «залы»: фото в рамке крупнее текста, паспорт под фото. Фото из `img/mono` — дуотон, в паспарту, не крупнее исходника (слабые кадры — малыми форматами, обложки — большими). Проверить: лайтбокс белый, hover обложек 1,015, `srcset`/`sizes` по колонке, CLS = 0 с плейсхолдерами; на телефоне — колонка с чередованием 3:2 / 4:5 и табличками.

### C — «Chapitres» (драматургия глав)
Белое тело и **полноэкранные чёрные главы как повороты сюжета**: ELUNA, «Для бизнеса», контакты + подвал занимают всю ширину, резкая кромка, внутри — ритм спек-страниц Apple: один тезис на экран, **большие цифры** (Unbounded 300 для ELUNA: 7 · 300 мм · 1 200 · 100; Cormorant 500 для RICCA: «3 года», «5 шагов», «SCM · Dürkopp Adler»), белый спек-блок внутри чёрной ELUNA как «лист внутри книги». Белые секции между главами — сдержанные, строго по системе, чтобы чёрные повороты читались. «Для бизнеса» — один чёрный экран по `refs/05`: заголовок капителью Montserrat, лид по центру, много чёрного воздуха. Таблица сравнения и конфигуратор — крупные, цифры доминируют. Проверить главное: доля чёрного 25–35 % по высоте (не больше — основа должна оставаться белой), шапка и плашка над чёрным остаются белыми, пин ELUNA 170 %/120 %, `reduced-motion` даёт статичный разрез, кромки без градиентов.

## Что сдаёт каждый сборщик
1. `index.html` + `css/` + `js/` в своей папке `_panel/…`, работающие на 390 и 1440.
2. Скриншоты `shoot.js` (первый экран и вся страница, 1440 и 390) и JSON-отчёт без ошибок.
3. Короткий `NOTES.md` (≤ 20 строк): что исследовано, где отступили от чисел системы (±10 % допустимо) и почему, открытые вопросы.

Срок и порядок: сначала hero + шапка + проекты + одна категория + контакты/подвал (половина пути — показ), затем ELUNA, остальное. Любое противоречие между этим брифом и `DESIGN-V3.md` — в пользу `DESIGN-V3.md`; между ним и `BRIEF.md` — в пользу `BRIEF.md`.
