### 0.2 Голос RICCA
Ателье говорит как портной, который шьёт для дома: **мерка, крой, лекала, шов, посадка, примерка**. Коротко: одна мысль — одно предложение, заголовок до шести слов. Факт вместо эпитета: не «высочайшее качество», а «станки SCM и Dürkopp Adler». Спокойно, без восклицательных знаков (исключение — сообщения WhatsApp: это голос клиента). На «вы». Итальянское *su misura* — один раз, в манифесте.

Запрещено на сайте: «инновационные технологии», «непревзойдённое качество», «индивидуальный подход», «широкий ассортимент», «премиум/премиальный» о себе, «уникальный», «эксклюзивный», «элитный», «хит», «акция», «скидка» (кроме −20 % у Eluna Prime — это факт бренда ELUNA), «лечит», «исправляет осанку», «мебель вне времени», «комплектации объектов коммерческой недвижимости» (формулировка BOCA).

Разрешено о матрасах: «ортопедическая поддержка», «позвоночник остаётся в естественном положении» (так на сайте ELUNA).

### 0.3 Типографика (обязательно)
- Кавычки «ёлочки», внутри — „лапки“. Длинное тире с пробелами: «Ателье — в Алматы». Диапазоны — короткое тире без пробелов: Пн–Вс, 10:00–20:00, 1400–2200.
- Неразрывный пробел (U+00A0): после предлогов и союзов в одну-две буквы; перед тире; в числах с разрядами («125 000 ₸»); между числом и единицей («3 года», «21 день», «300 мм», «−20 %»); внутри телефонов; в «ул. Алишера Навои», «г. Алматы», «208/2», «ЖК «Шахристан»», «RICCA DESIGNS», «Eluna Prime». В этом деке неразрывные пробелы уже расставлены — копируйте тексты как есть. Для новых строк — функция `typo()` в разделе 28.4.
- Размеры — в миллиметрах, со знаком × (U+00D7): «1600 × 2000 мм». Деньги — «280 000 ₸» (символ тенге U+20B8, после числа, через неразрывный пробел).
- Буква «ё» обязательна. RICCA DESIGNS и ELUNA — заглавными; модели — Eluna Air / Balance / Prime / Royal (в карточках коротко: Air, Balance, Prime, Royal). Dürkopp Adler — с умлаутом. 2ГИС — кириллицей.
- Надзаголовки (eyebrow) в HTML обычным регистром, капс и разрядка — через CSS. Точку в конце заголовка не ставим; исключение — заголовок из двух предложений («Семь слоёв. Одно ощущение.»).

```js
const PRICES = { air: 125000, balance: 220000, prime: 280000, royal: 1250000 };
const OLD = { prime: 350000 };
const PER_M2 = 40000;
function priceOf(model, w, h) {
  if (model === 'royal') return { v: PRICES.royal, old: null, custom: false };
  const dA = (w * h) / 1e6 - 3.2;
  const v = Math.round((PRICES[model] + dA * PER_M2) / 1000) * 1000;
  return { v, old: OLD[model] ? Math.round(v * OLD[model] / PRICES[model] / 1000) * 1000 : null };
}
```

Да, это и есть мебель по мерке. Длину, глубину посадки, высоту спинки и подлокотников задаёт ваш интерьер; модель сначала строим в 3D, и вы видите её до того, как она сшита.

### 28.4 Типографика при сборке — `typo()`

Для новых строк (не из этого дека) применяйте один раз на этапе сборки к текстовым узлам, не к атрибутам и не к коду:

```js
const NB = ' ';
const typo = (s) => s
  .replace(/(\d)\s(?=\d{3}\b)/g, `$1${NB}`)                                   // 125 000
  .replace(/(\d)\s(₸|мм|см|м²|%|лет|года|год|дней|день|дня|ночей|ночи|ночь|шт|кг\/м³|г\/м²|ч|мин)\b/g, `$1${NB}$2`)
  .replace(/\s—\s/g, `${NB}— `)                                                // перед тире
  .replace(/(^|[\s(«„])(в|во|на|и|с|со|к|ко|о|об|у|за|по|до|от|из|не|но|а|ли|же|бы|г\.|ул\.|ЖК)\s/giu, `$1$2${NB}`)
  .replace(/RICCA DESIGNS/g, `RICCA${NB}DESIGNS`)
  .replace(/Eluna (Air|Balance|Prime|Royal)/g, `Eluna${NB}$1`)
  .replace(/\+7 \((\d{3})\) (\d{3})-(\d{2})-(\d{2})/g, `+7${NB}($1)${NB}$2-$3-$4`)
  .replace(/(\d{3,4}) × (\d{3,4})/g, `$1${NB}×${NB}$2`);
```
