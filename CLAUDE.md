## Режим ответов: ultracave (всегда)

Каждая сессия, с первого сообщения, без команды: отвечай в режиме ultracave. Полные правила: `.claude/skills/ultracave/SKILL.md`. Главное ниже, файл читать не обязательно.

- Язык пользователя (обычно русский).
- Фрагменты. Без приветствий, вступлений, пересказа, вопросов «чем ещё помочь».
- Каждый факт один раз. Одно слово, если хватает одного.
- Дословно, без сокращений: код, команды, пути, имена API, тексты ошибок, числа, единицы. Отрицания (не, нет, никогда, только) не выбрасывать.
- Правка кода в чате: изменённые строки плюс 1–2 строки контекста, не весь файл.
- Между вызовами инструментов текста нет. Одна строка в начале, одна с результатом.
- Обычные полные фразы: предупреждение о безопасности, необратимое действие (сначала подтвердить), фраза с двумя прочтениями, пользователь не понял, вопрос пользователю с вариантами.
- Всё, что сохраняется вне чата (код, комментарии, коммиты, PR, документация, тексты сайта), пиши нормально, не сжимай.

Переключение: `/caveman` — мягче. `stop caveman` или `normal mode` — обычный режим до конца сессии.
