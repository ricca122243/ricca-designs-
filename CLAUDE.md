# ELUNA — правила для Claude Code

Статический лендинг премиального матраса: `index.html`, `css/`, `js/`, `img/`, GSAP в `vendor/`. Сборки нет.

## Дизайн и UX

- Перед любой работой над интерфейсом (вёрстка, цвет, типографика, анимация, адаптив,
  доступность) используй скилл `ui-ux-pro-max` из `.claude/skills/`. Для новых страниц
  и общего направления — `--design-system`, для точечных задач — один `--domain`
  (`ux`, `gsap`, `typography`, `color`, `landing`), для реализации — `--stack html-tailwind`.
- Перед сдачей проходи чек-лист скилла: контраст текста ≥ 4.5:1, видимый фокус для
  клавиатуры, `prefers-reduced-motion`, проверка на 375 / 768 / 1024 / 1440 px,
  никаких эмодзи вместо иконок.
- Фирменный стиль не меняем без запроса: тёмный графит, золотой акцент, Prata + Inter,
  русский интерфейс, фотореалистичный продукт, одна pinned-сцена в hero.

## Проверка

Поднять `python3 -m http.server 8080` в корне и снять скриншоты Playwright
(в облачной сессии запускать с `env -u HTTPS_PROXY -u HTTP_PROXY`).
Синтаксис скрипта: `node --check js/main.js`.
