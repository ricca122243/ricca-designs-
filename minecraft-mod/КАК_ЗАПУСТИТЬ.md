# Как собрать и запустить мод (NeoForge 1.21.1, ModDevGradle)

Мод **Civilizations** для Minecraft 1.21.1 на загрузчике NeoForge 21.1.252.
Папка `minecraft-mod/` — отдельный проект, к сайту в корне репозитория он не относится.

## Что уже есть в моде

**Этап 1 — основа.**
- **Королевская грамота** — кликните правой кнопкой по земле: появится Ратуша и четверо поселенцев.
- **Ратуша** — сердце королевства. Правый клик по ней показывает сводку: жители, дома, склад.
- **Рыцарский меч** — сильнее железного. **Яйцо призыва поселенца** — поселенец сам найдёт ратушу.

**Этап 2 — профессии, ресурсы, рост, воины.**
- **Строитель** ставит дома 5×5 рядом с ратушей, тратя дерево и камень со склада. Участков под дома — 8.
  На холмах сначала расчищает площадку (выкопанный камень идёт на склад) и подсыпает фундамент в ямы.
- **Дровосек** ищет деревья в радиусе 18 блоков, рубит их снизу вверх, сажает саженец. Одно бревно = 4 дерева на складе.
- **Фермер** разбивает поле 5×5 к северу от ратуши: пашет, льёт воду в центр, сажает пшеницу, ухаживает и собирает урожай. Урожай = 3 еды.
- **Воин** защищает королевство: нападает на монстров рядом, не убегает, у него больше здоровья и урон.
- **Рост.** Каждые 30 секунд ратуша проверяет: если еды ≥ 15 и жителей меньше, чем 4 + 2 на каждый дом, рождается новый житель со случайной профессией. Еду даёт фермер.
- У каждой профессии своя одежда, над головой подпись: «Фермер королевства Dev».

**Этап 3 — управление, золото, стража, территория.**
- **Жезл командира** (выдаётся при основании, крафт: золото + 2 палки по диагонали). Клик по жителю — выбрать;
  ещё клик — следовать за вами / отпустить; Shift+клик — сменить профессию; клик по земле — отправить выбранного туда.
  Клик в воздух — список королевств с расстоянием и направлением. У каждого игрока свой жезл, работает в мультиплеере.
- **Стражник** — новая профессия. Отправьте его жезлом в точку: он встанет там на пост и будет защищать его.
- **Золото.** Казна в ратуше. Раз в минуту каждый житель платит 1 золото; излишки дерева и камня (больше 150)
  продаются по 50 за 10 золота. Shift+клик жезлом по ратуше — нанять строителя за 50 золота.
- **Обмен.** Кликните по ратуше с предметом в руке: бревно = 4 дерева, доски = 1, булыжник/камень = 1 камень,
  пшеница/морковь/картошка = 1 еда, хлеб = 3, золотой слиток = 5 золота, изумруд = 10.
- **Территория.** Радиус 20 блоков + 5 за каждый дом. Пока держите жезл, граница ближайшего королевства
  подсвечивается белыми частицами.

Дальше по плану: три НПС-королевства при создании мира, их рост и конфликты, карта земель, вселение в жителя.

## 1. Что нужно установить

- **Java 21** (JDK, не JRE). Скачать: https://adoptium.net/ (Temurin 21).
  Проверка в терминале:
  ```
  java -version
  ```
  Должно быть `openjdk version "21...."`. Если стоит другая версия — поставьте 21,
  Minecraft 1.21.1 работает только на ней.
- Gradle ставить **не нужно**: скрипт `gradlew` сам скачает нужную версию (9.2.1).

## 2. Удобный способ: через Git (один раз настроить, дальше одна кнопка)

1. Установите Git для Windows: https://git-scm.com/download/win (жмите «Next» до конца).
2. Создайте папку, например `C:\mods`, откройте её, в адресной строке напишите `cmd`, Enter.
3. Выполните один раз:
   ```
   git clone -b claude/vigilant-hopper-eo0cn0 https://github.com/ricca122243/ricca-designs-.git civ
   ```
4. Дальше каждый раз просто открывайте `C:\mods\civ\minecraft-mod` и запускайте двойным кликом
   файл `ОБНОВИТЬ_И_ЗАПУСТИТЬ.bat`. Он сам скачает последнюю версию и откроет игру.

## 3. Первый запуск (способ без Git)

Откройте терминал в папке `minecraft-mod` и выполните:

Windows:
```
gradlew.bat build
gradlew.bat runClient
```

Linux / macOS:
```
./gradlew build
./gradlew runClient
```

Первая сборка качает около 500 МБ (Gradle, NeoForge, библиотеки Minecraft) и может
идти 5–15 минут. Дальше всё берётся из кэша и запускается за полминуты.

`build` — собирает jar мода в `build/libs/civilizations-1.0.0.jar`.
`runClient` — запускает Minecraft с модом в режиме разработки (папка `run/`).
Войти можно без аккаунта Mojang: игра стартует с офлайн-профилем `Dev`.

Проверить, что мод работает: в творческом режиме появится вкладка «Цивилизации».
Возьмите Королевскую грамоту, кликните ей по земле на ровном месте и отойдите:
поселенцы начнут строить дома.

## 4. Открыть в IDE

IntelliJ IDEA (Community бесплатна): File → Open → выбрать папку `minecraft-mod`
(именно её, а не корень репозитория). IDEA сама подтянет Gradle и создаст
конфигурации запуска `runClient`, `runServer`, `runData`.

## 5. Где что лежит

| Файл | Зачем |
|---|---|
| `gradle.properties` | версии Minecraft/NeoForge, `mod_id`, имя и версия мода |
| `build.gradle` | сборка, конфигурации запуска |
| `src/main/java/com/ricca/civilizations/` | код мода |
| `.../entity/SettlerEntity.java` | поселенец: здоровье, поведение, сохранение |
| `.../entity/BuildHouseGoal.java` | строитель: план дома и как он строится |
| `.../entity/ChopTreesGoal.java` | дровосек |
| `.../entity/FarmGoal.java` | фермер |
| `.../entity/KingdomLayout.java` | где стоят дома и поле относительно ратуши |
| `.../block/TownHallBlockEntity.java` | склад ресурсов, рост населения |
| `.../item/KingdomCharterItem.java` | что происходит при клике грамотой |
| `src/main/templates/META-INF/neoforge.mods.toml` | описание мода для загрузчика |
| `src/main/resources/assets/civilizations/` | текстуры, модели, переводы (en_us, ru_ru) |
| `src/main/resources/data/civilizations/` | рецепты и таблицы дропа |

## 6. Частые ошибки

- **`Unsupported class file major version`** или **`invalid source release: 21`** —
  запущена не Java 21. Проверьте `java -version` и переменную `JAVA_HOME`.
- **`Could not resolve net.neoforged:...` / `403` / `timeout`** — нет доступа к
  `maven.neoforged.net` или `libraries.minecraft.net`. Проверьте интернет,
  VPN, антивирус или корпоративный прокси. Повторите `gradlew --refresh-dependencies`.
- **Сборка зависла или странные ошибки после обновления** — `gradlew clean`, затем снова `build`.
- **Не хватает памяти** — увеличьте `org.gradle.jvmargs=-Xmx1G` в `gradle.properties` до `-Xmx2G`.
