# ELUNA — матрас, который раскрывается слой за слоем

Лендинг премиального матраса ELUNA. Статический сайт без сборки: `index.html`, `css/`, `js/`, `img/`, локальные шрифты и GSAP в `vendor/`.

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx http-server -p 8080 .
```

## Как устроен hero

Первый экран — космическая темнота: небо на двух canvas (статичный слой со звёздами разной
яркости и цвета, ореолами и полосой Млечного Пути, рисуется один раз; поверх — мерцание и редкие
метеоры; параллакс по скроллу), туманности, кольцо затмения.
Фотореалистичный матрас проявляется постепенно: свет расширяется радиальной маской,
экспозиция поднимается, затем над продуктом возникает имя ELUNA.

- **Интро (≈7 с)** — темнота → свет → силуэт → фактура → имя. GSAP‑таймлайн по времени.
- **Скролл (pinned, GSAP ScrollTrigger)** — «камера» облетает продукт (перспектива,
  наклон, наезд; параллакс от указателя), имя растворяется в навигацию, фото сменяется
  разрезом. Разлёт слоёв — это 24 кадра (`img/seq/f01…f24.webp`) из сгенерированного
  видео, которые рисуются на canvas и скрабятся скроллом (соседние кадры смешиваются,
  поэтому движение гладкое); фокус идёт по слоям сверху вниз, затем они собираются обратно.
  Сцена гаснет и переходит в манифест на том же чёрном.
- **Линейка** — сверху выбор модели «по уровням света»: наведение на строку (Air / Balance /
  Prime / Custom) переводит луч, кольцо и блик на сцене, уровень задаёт силу света. Ниже —
  Air / Balance / Prime в шахматной раскладке, Prime — акцентный блок с бейджем,
  отзывами и разлётом слоёв при появлении. Разрезы моделей рисуются CSS‑слоями из данных
  `MODELS` в `js/main.js`; цены — объект `PRICES` там же (`null` → «— ₸», «за ночь» считается
  как цена / (15 × 365)); `OLD_PRICES` задаёт полную цену до скидки (у Prime 350 000 → 280 000,
  бейдж «−20 %» и зачёркнутая старая цена появляются везде автоматически). Кнопки ведут в WhatsApp (`WHATSAPP`) с готовым текстом. Под линейкой —
  преимущества с SVG‑иконками и три карточки «чем отличаются» (Prime светится, на мобильном идёт
  первой), плюс липкая плашка Prime на мобильном.
- **Сон вдвоём** — поверхность матраса как цепочка масс и пружин на canvas: «Повернуться»
  (кнопка, клик по матрасу или авто раз в несколько секунд) запускает волну на стороне А,
  у центрального шва связь ослаблена и затухание выше, сторона Б почти не двигается.

Интро и скролл пишут в разные объекты состояния; `render()` сводит их, поэтому
ранний скролл не ломает вступление — только ускоряет его.

## Структура

```
index.html          разметка всех секций (hero‑сцена, манифест, материалы, сон вдвоём, линейка, размеры, CTA)
css/styles.css      стили, сцена, маски, адаптив
css/fonts.css       Prata + Inter (latin, cyrillic), локально
js/main.js          сцена, интро, скролл, сон вдвоём, линейка (PRICES / MODELS / WHATSAPP), размеры
img/                webp: hero, разрез, бок матраса, текстуры материалов
img/seq/            24 кадра разлёта слоёв (скролл-секвенция)
vendor/             gsap.min.js, ScrollTrigger.min.js
fonts/              woff2
```
