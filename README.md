# ELUNA — матрас, который раскрывается слой за слоем

Лендинг премиального матраса ELUNA. Статический сайт без сборки: `index.html`, `css/`, `js/`, локальные шрифты и GSAP в `vendor/`.

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx http-server -p 8080 .
```

## Как устроен hero

В первом экране нет фотографии продукта. Матрас собран из семи CSS‑3D слоёв
с процедурными текстурами (стёжка, латекс, гель, койра, пена, пружины, основание),
бортовой тканью и кантом. Свет — радиальные градиенты на гранях, луч и пыль на canvas.

- **Интро (≈7 с)** — темнота → луч → силуэт → фактура → имя. GSAP‑таймлайн по времени.
- **Скролл (pinned, GSAP ScrollTrigger)** — свет движется, камера разворачивает объект,
  имя растворяется в навигацию, слои раскрываются по одному, собираются обратно,
  сцена гаснет и переходит в манифест на том же чёрном.

Интро и скролл пишут в разные объекты состояния; `render()` сводит их, поэтому
ранний скролл не ломает вступление — только ускоряет его.

## Структура

```
index.html          разметка всех секций (hero‑сцена, манифест, материалы, конструкция, размеры, CTA)
css/styles.css      стили, 3D‑объект, текстуры, адаптив
css/fonts.css       Cormorant Garamond + Manrope (latin, cyrillic), локально
js/main.js          сцена, интро, скролл, интерактив конструкции и размеров
vendor/             gsap.min.js, ScrollTrigger.min.js
fonts/              woff2
```
