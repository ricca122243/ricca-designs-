# ricca-designs-

## ELUNA — сайт матрасов (Sleep Tech)

- **`ELUNA.html`** — весь сайт одним файлом (стили, скрипты, шрифты и картинки внутри). Открывается двойным кликом, работает без сервера и интернета.
- **`eluna/`** — исходники для хостинга (Netlify / любой статический хостинг): `index.html`, `css/`, `js/`, `img/`, `fonts/`, `vendor/`, `privacy.html`, `legal.html`.
- **`eluna/tools/build_single.py`** — пересборка единого файла: `python3 eluna/tools/build_single.py eluna ELUNA.html`.

### Что внутри
- **Hero** — луна (WebGL), логотип, короткая сцена скролла.
- **Расслойка** (`#layers`, `js/strata.js`) — «7 слоёв. Одно ощущение.»: список 01–07 слева, матрас справа. Матрас закрыт, пока посетитель не нажмёт «Открыть»; «Закрыть» собирает слои обратно. Наведение/нажатие на строку или слой подсвечивает его и показывает описание.
- **Космос** — снимок глубокого неба `img/space-*.webp` + редкие мерцающие звёзды и метеоры.
- Концепция, Технология, Модели, Размер, Доставка (карта Казахстана), оформление в WhatsApp.
