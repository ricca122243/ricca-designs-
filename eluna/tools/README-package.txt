ELUNA — сайт, готовый к загрузке на хостинг
===========================================

ЧТО В АРХИВЕ
------------

  site/             Сайт целиком — ОСНОВНОЙ вариант для хостинга
                    (index.html, css, js, img, fonts и т.д.).

  site-upload.zip   То же, что папка site/, но уже упаковано так,
                    как нужно хостингу: файлы лежат прямо в корне архива.
                    Для хостинга с панелью — загрузил и нажал «Извлечь».

  single-file/      Тот же сайт одним файлом index.html (около 3 МБ).
                    Внутри уже всё: картинки, шрифты, стили, скрипты,
                    «Политика конфиденциальности» и «Авторские права».
                    Запасной вариант: если хостинг или конструктор принимает
                    только один файл, или чтобы открыть сайт на компьютере
                    двойным щелчком — даже без интернета.

  tools/            Для разработчика: сборщик single-file из папки site.

  README.txt        Этот файл.

Какой вариант выбрать: если есть возможность — site/ (или site-upload.zip).
Он открывается быстрее (браузер грузит картинки параллельно и запоминает их),
и луна в нём в максимальном качестве (карта 4096 px).
Сайт из single-file выглядит и работает так же, только первая загрузка
дольше (3 МБ одним куском), а луна — в разрешении 2048 px.


ШАГ 0. ПЕРЕД ПУБЛИКАЦИЕЙ — РЕКВИЗИТЫ
------------------------------------

На страницах «Политика конфиденциальности» и «Авторские права» оставлены
места под реквизиты — они подсвечены золотым и выглядят так: [заполнить].
Это данные вашей компании, их нельзя придумывать:

  • форма и наименование (ИП / ТОО …)
  • БИН / ИИН
  • юридический адрес
  • e-mail для обращений
  • товарный знак «ELUNA»: номер свидетельства, «заявка подана»
    или удалить эту строку

Проще всего — прислать эти данные разработчику: он впишет их
и пересоберёт все варианты (site, site-upload.zip, single-file).

Если вписываете сами: файлы site/privacy.html и site/legal.html,
ищите слово «заполнить». Открывайте как текст — в Windows Блокнотом.
На Mac сначала в TextEdit → Настройки → «Открытие и сохранение» включите
«Показывать файлы HTML как код HTML» и только потом открывайте файл
(иначе TextEdit покажет страницу как документ и испортит код при сохранении).
После этого загружайте папку site/ (п. 1 «вручную» или п. 2 Netlify) —
site-upload.zip и single-file содержат старые файлы, их не используйте.


КАК ЗАГРУЗИТЬ
-------------

1) Обычный хостинг с панелью (cPanel, ISPmanager, ps.kz, hoster.kz и т.п.)
   • Откройте «Файловый менеджер» → папку сайта
     (обычно public_html, www или htdocs).
   • Загрузите туда файл site-upload.zip, нажмите «Извлечь» (Extract),
     затем удалите сам site-upload.zip.
     Не загружайте на хостинг ELUNA-hosting.zip целиком — внутри него
     лишние папки, и сайт окажется по адресу ваш-домен/ELUNA/site/.
   • Если загружаете файлы вручную — берите ВСЁ содержимое папки site/,
     включая скрытый файл .htaccess (на Mac скрытые файлы показывает
     Cmd+Shift+точка, в Windows — «Вид» → «Скрытые элементы»).
     В .htaccess: своя страница 404, сжатие и кеш.
   • Если после загрузки сайт показывает «500 Internal Server Error» —
     удалите файл .htaccess: без него сайт тоже работает.

2) Netlify
   • Сначала войдите или зарегистрируйтесь на netlify.com (бесплатно):
     без входа сайт получится временным.
   • Затем откройте https://app.netlify.com/drop и перетащите папку site
     целиком в окно браузера. Файл _headers включит правильный кеш.
   • Имя сайта и свой домен меняются в настройках сайта на Netlify
     (раздел Domain management).

3) Cloudflare Pages / Vercel
   • Папка публикации (output directory) — site. Сборка не нужна:
     это готовая статика.

4) GitHub Pages
   • Положите СОДЕРЖИМОЕ site/ в корень репозитория (или переименуйте
     папку site в docs) и в Settings → Pages выберите ветку
     и папку / (root) или /docs.
   • Лучше со своим доменом или в репозитории вида имя.github.io —
     иначе сайт будет по адресу …/имя-репозитория/ и не будет работать
     своя страница 404 (остальное работает).

5) Один файл
   • Загрузите single-file/index.html в корень сайта — и всё.
     Больше ничего не нужно.

После загрузки проверьте:
   • главная открывается;
   • на компьютере — пункт меню «Слои», на телефоне — пролистайте до блока
     «7 слоёв. Одно ощущение.» → кнопки «Открыть» / «Закрыть» работают;
   • внизу страницы — ссылка «Политика конфиденциальности» открывается.


ВАЖНО
-----

• Не переименовывайте файлы и папки: сайт ищет их по именам,
  а на хостинге важен даже регистр букв (Img ≠ img).
• На обычном хостинге (п. 1) загружайте СОДЕРЖИМОЕ site/ в корень сайта.
  Если загрузить саму папку, сайт откроется по адресу ваш-домен/site/,
  а не на главной, и своя страница 404 будет без оформления.
  (На Netlify — наоборот: перетаскивается сама папка site.)
• Если после обновления видна старая версия — обновите страницу
  с очисткой кеша (Ctrl+F5, на Mac Cmd+Shift+R).


ДЛЯ РАЗРАБОТЧИКА
----------------

  Номер WhatsApp ...... site/js/main.js:  const WHATSAPP = '77079550808'
                        а также вручную (ссылки wa.me/… и номер текстом):
                        site/index.html — подвал и кнопка заказа,
                        site/privacy.html и site/legal.html.
  Цены ................ site/js/main.js:  const PRICES = { air, balance, prime, royal }
                        и  const OLD_PRICES  (старая цена → скидка считается сама)
                        доплата за нестандартный размер — const PER_M2 в main.js
                        и текст «±40 000 ₸ за каждый м²» в site/index.html (блок размеров)
  Отзывы Prime ........ site/js/main.js:  const REVIEWS = { prime: [ ... ] }
                        Внутри — закомментированные образцы: отзыв покупателя
                        и «Мнение специалиста» (врач). Пока список пуст,
                        в ленте показываются шаблоны «Здесь появится отзыв…».
                        Добавляйте только настоящие отзывы.
  Отзывы из формы ..... приходят в WhatsApp на номер выше; на сайт
                        переносятся вручную в REVIEWS после проверки.
  Реквизиты ........... site/privacy.html, site/legal.html — всё, что [заполнить].

  После правок в site/ пересоберите вариант одним файлом (нужен Python 3),
  находясь в этой папке:

      python3 tools/build_single.py site single-file/index.html

  и заново упакуйте site-upload.zip (всё содержимое site/, включая .htaccess,
  в корень архива).

  Кеш браузеров:
  • css/js: при изменении увеличьте номер ?v=15 во всех ссылках
    в site/index.html, site/privacy.html, site/legal.html и site/404.html.
  • картинки и шрифты кешируются на год: новое фото сохраняйте под НОВЫМ
    именем (например moon-hd-2.webp) и поменяйте ссылку в html/css/js.
